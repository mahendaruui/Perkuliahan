🔄 Evolusi Paradigma

PHP Prosedural vs PHP Modern (OOP)

Bagaimana cara penulisan kode PHP berevolusi dari skrip sederhana ke arsitektur enterprise:

PENDEKATAN PROSEDURAL (PHP 4/5 Tradisional)

• Fungsi dan data terpisah (data mengalir bebas).
• Mengandalkan fungsi global function hitung().
• Sulit di-maintain saat file mencapai ribuan baris.
• Berisiko bentrok nama fungsi (name collision). 

// Prosedural: Data dan fungsi terpisah
function hitungDiskon($total, $persen) {
    return $total * ($persen / 100);
}
$total = 100000;
$diskon = hitungDiskon($total, 10);
PENDEKATAN BERORIENTASI OBJEK (PHP 8+)

• Data dan fungsi dibungkus ke dalam Class & Objek.
• Menggunakan Type Hinting & validasi data ketat.
• Sangat modular, aman, dan mudah diuji (Unit Test).
• Fondasi utama framework modern (Laravel & Symfony). 

// OOP PHP 8+: Constructor Promotion
class Pesanan {
    public function __construct(
        private float $total,
        private float $persenDiskon = 0
    ) {}

    public function hitungTotalAkhir(): float {
        return $this->total * (1 - $this->persenDiskon / 100);
    }
}
🏛️ Fondasi Fundamental

4 Pilar Utama OOP di PHP

Prinsip dasar yang diterapkan dalam seluruh siklus rekayasa perangkat lunak berorientasi objek:

🔒
1. Encapsulation
Melindungi properti dengan private / protected serta readonly (PHP 8.1), akses data melalui getter/setter yang tervalidasi.
🧬
2. Inheritance
Pewarisan hierarkis menggunakan extends dan pemanggilan parent::, serta Trait untuk horizontal code reuse di PHP.
🎭
3. Polymorphism
Perilaku berbeda melalui Method Overriding dan Type Hinting parameter yang menerima instance parent class atau interface.
🧩
4. Abstraction
Memisahkan kontrak fungsi dan detail teknis melalui abstract class dan interface untuk decoupling sistem.
⚡ Modern Features

Fitur Mutakhir PHP 8+ untuk OOP

PHP 8 membawa revolusi besar dalam sintaks dan performa OOP modern:

PHP 8.0
Constructor Promotion
Deklarasi visibilitas dan tipe properti langsung di parameter constructor — bebas boilerplate!
PHP 8.0
Union Types & Named Args
Tipe fleksibel seperti int|float dan pemanggilan parameter dengan nama parameter eksplisit.
PHP 8.1
Pure & Backed Enums
Tipe data enumerasi native dengan method pendukung untuk validasi status atau kategori.
PHP 8.1
Readonly Properties
Properti immutability yang hanya bisa diisi satu kali saat objek dikonstruksi.
PHP 8.0
Nullsafe Operator (?->)
Pencegahan error null pointer saat chaining method: $user?->getProfile()?->getCity().
PHP 8.2
Readonly Classes
Seluruh properti dalam class otomatis berstatus readonly untuk Data Transfer Objects (DTO).
💻 Live Code

Memodelkan Objek: "AkunBank"

Penerapan Constructor Promotion, Encapsulation, dan Type Hints di PHP 8+:

<?php
declare(strict_types=1);

class AkunBank {
    // PHP 8 Constructor Promotion + Readonly
    public function __construct(
        public readonly string $nomorRekening,
        public string $pemilik,
        private float $saldo = 0.0
    ) {}

    public function getSaldo(): float {
        return $this->saldo;
    }

    public function setor(float $jumlah): void {
        if ($jumlah <= 0) {
            throw new \InvalidArgumentException("Setoran harus > 0");
        }
        $this->saldo += $jumlah;
    }
}


            
              // Penggunaan Objek (Client Code)
$rekening = new 
AkunBank(
    nomorRekening: "123-456-789",
    pemilik: "Budi Santoso",
    saldo: 500_000
);

// Akses Properti & Method
echo "Pemilik : " . $rekening->pemilik . "\n";
$rekening->setor(250_000);

echo "Saldo Akhir: Rp " . 
     number_format($rekening->getSaldo(), 0, ',', '.');

// Output:
// Pemilik : Budi Santoso
// Saldo Akhir: Rp 750.000
📦 Modularitas Proyek

Namespace & Composer (PSR-4)

Standar profesional pengorganisasian kode proyek PHP di industri:

📂
1. Namespace
Mencegah bentrok nama class antar modul atau library pihak ketiga: namespace App\Model;
🎼
2. Composer
Package manager resmi PHP untuk mengelola dependensi dan menghasilkan class autoloader otomatis.
🚀
3. PSR-4 Autoloading
Tidak perlu lagi memanggil puluhan require_once secara manual di setiap file!
Struktur Folder Project Standar:
project-root/ ➔ composer.json | src/ (Model/, Service/, Exception/, Repository/) | data/ | public/ (index.php)
