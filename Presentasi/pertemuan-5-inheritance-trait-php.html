🧬 Pilar 2 OOP

Konsep Inheritance: Relasi "Is-A"

Subclass mewarisi seluruh kapabilitas Superclass secara vertikal:

Superclass (Parent): Kendaraan

Mendefinisikan atribut & perilaku umum yang dimiliki oleh SEMUA kendaraan:
• $merk, $tahunProduksi
• infoKendaraan(), klakson()

Subclasses (Child): Mobil & Motor

Mewarisi seluruh sifat Kendaraan, lalu menambahkan fitur spesifik:
• Mobil: $jumlahPintu, nyalakanAC()
• Motor: $adaBox, wheelie()

🏗️ Sintaks Pewarisan

Keyword extends & parent::

Menghubungkan child class dan meneruskan parameter ke constructor induk:

// Superclass
class Kendaraan {
    public function __construct(
        protected string $merk,
        protected int $tahun
    ) {}
}

// Subclass: mewarisi Kendaraan
class Mobil extends Kendaraan {
    public function __construct(
        string $merk,
        int $tahun,
        private int $jumlahPintu = 4
    ) {
        // Wajib panggil constructor parent!
        parent::__construct($merk, $tahun);
    }
}
⚡ Kustomisasi Perilaku

Method Overriding

Subclass dapat menimpa method induk dan menggabungkannya dengan parent:::

class Mobil extends Kendaraan {
    // Override method infoKendaraan()
    public function infoKendaraan(): void {
        // 1. Panggil implementasi parent
        parent::infoKendaraan();

        // 2. Tambahkan info khusus mobil
        echo "Pintu : {$this->jumlahPintu} unit\n";
    }
}

$avanza = new Mobil("Toyota", 2024);
$avanza->infoKendaraan();
Kapan Menggunakan Overriding?
• Saat logika di parent terlalu umum (contoh: hitungGaji() parent hanya return gaji pokok, tapi subclass Manager harus menambah tunjangan).

• Menggunakan parent::method() memastikan kita tidak kehilangan logika validasi bawaan superclass.
🔒 Pembatasan Keamanan

Kata Kunci final

Mencegah class diwarisi atau method ditimpa oleh developer lain:

1. Final Class (Tidak Bisa Di-extends)
final class KonfigurasiSistem {
    // Aman dari modifikasi pewarisan
}

// 💥 Fatal Error: Class CustomConfig 
// cannot extend final class
class CustomConfig extends KonfigurasiSistem {}
2. Final Method (Tidak Bisa Di-override)
class Bank {
    final public function hitungPajakDasar() {
        // Rumus baku regulasi pemerintah
    }
}

// 💥 Fatal Error: Cannot override 
// final method Bank::hitungPajakDasar()
🧩 Horizontal Code Reuse

Solusi Single Inheritance: Trait

Menyisipkan kumpulan method ke berbagai class tanpa ikatan relasi keluarga (*use Trait*):

// Trait 1: Pencatat Log Waktu
trait Loggable {
    public function log(string $pesan): void {
        echo "[" . date('H:i:s') . "] [" . static::class . "] {$pesan}\n";
    }
}

// Trait 2: Serialisasi JSON
trait Exportable {
    public function toJSON(): string {
        return json_encode(get_object_vars($this));
    }
}

class Produk {
    use Loggable, Exportable; // Pasang 2 trait sekaligus!
}
🛠️ Resolusi Konflik

Resolusi Konflik Trait (insteadof & as)

Bagaimana jika dua trait memiliki nama method yang sama?

trait A { public function cetak() { echo "Dari Trait A\n"; } }
trait B { public function cetak() { echo "Dari Trait B\n"; } }

class Laporan {
    use A, B {
        // Pilih method milik Trait A daripada Trait B
        A::cetak insteadof B;

        // Buat alias untuk method milik Trait B agar tetap bisa dipanggil
        B::cetak as cetakVersiB;
    }
}

$lap = new Laporan();
$lap->cetak();        // Output: Dari Trait A
$lap->cetakVersiB();  // Output: Dari Trait B
💼 Praktikum Terbimbing

Studi Kasus: Sistem Hirarki Karyawan

Mengintegrasikan Parent Karyawan, Subclass Manager, Subclass Programmer, dan Trait:

class Karyawan {
    public function __construct(
        protected string $nama,
        protected float $gajiPokok
    ) {}
    public function hitungGaji(): float {
        return $this->gajiPokok;
    }
}

class Manager extends Karyawan {
    public function __construct($nama, $gaji, private float $tunjangan) {
        parent::__construct($nama, $gaji);
    }
    public function hitungGaji(): float {
        return $this->gajiPokok + $this->tunjangan;
    }
}
Keunggulan Desain Ini:
• Kode Superclass Ringkas: Properti $nama dan $gajiPokok cukup dideklarasikan 1 kali di parent.

• Extensibility: Menambah divisi baru (misal: SalesExecutive dengan komisi penjualan) cukup membuat class baru extends Karyawan tanpa menyentuh kode Manager.
