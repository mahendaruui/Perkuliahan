🧠 FILOSOFI LOGIKA BOOLEAN

Dari Logika Formal Menuju Sirkuit Komputer

Bagaimana matematika George Boole menjadi nyawa dari seluruh prosesor modern

🏛️ Warisan George Boole (1854)

Dalam karyanya The Laws of Thought, George Boole membuktikan bahwa seluruh penalaran logika manusia dapat disederhanakan menjadi sistem aljabar dua nilai: Benar (1) dan Salah (0).

Claude Shannon (1937) menghubungkan aljabar ini dengan saklar relay listrik, melahirkan gerbang logika (logic gates AND, OR, NOT) yang mendasari CPU mikroprosesor saat ini.

⚡ Konsep Ekspresi & Kausalitas

Dalam pemrograman, Operator adalah kata kerja (verb), Operand adalah kata benda (noun), dan Ekspresi adalah kalimat utuh yang menghasilkan sebuah kesimpulan nilai baru (result).

🧠 LOGIKA BOOLEAN & EFISIENSI

Operator Logika & Short-Circuit Evaluation

Optimasi evaluasi logika: Mengapa komputer tidak memeriksa seluruh kondisi?

1. Logika AND (&&)

Bernilai true HANYA JIKA semua kondisi bernilai true.

2. Logika OR (||)

Bernilai true JIKA salah satu kondisi bernilai true.

3. Logika NOT (!)

Pembalikan nilai: !true -> false, !false -> true.

⚡ Short-Circuit Guard:

Kompilator menghentikan pembacaan kondisi begitu hasil akhir sudah pasti: 

// Melindungi dari error pembagian nol (Crash):
if (pembagi != 0 && total / pembagi > 10) {
    // Jika pembagi == 0, bagian kanan
    // TIDAK PERNAH DIJALANKAN (Aman!)
}

💻 STUDI KASUS KOMPUTASI

Studi Kasus: Sistem Uji Tahun Kabisat

Harmoni antara operator modulus aritmatika, perbandingan, dan logika boolean

🐍 Python 3
# Algoritma Tahun Kabisat
tahun = int(input("Masukkan tahun: "))

# Logika Formal Kabisat:
is_kabisat = (tahun % 400 == 0) or (tahun % 4 == 0 and tahun % 100 != 0)

if is_kabisat:
    print(f"Tahun {tahun} adalah KABISAT (366 hari)")
else:
    print(f"Tahun {tahun} BUKAN Kabisat (365 hari)")
⚡ C++
#include <iostream>
using namespace std;

int main() {
    int tahun;
    cout << "Masukkan tahun: "; cin >> tahun;

    bool isKabisat = (tahun % 400 == 0) || (tahun % 4 == 0 && tahun % 100 != 0);

    if (isKabisat) {
        cout << tahun << " adalah KABISAT\n";
    } else {
        cout << tahun << " BUKAN Kabisat\n";
    }
    return 0;
}
