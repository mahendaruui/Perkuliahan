🧠 FILOSOFI STRUKTUR DATA

Mengapa Kita Membutuhkan Array?

Dari variabel skalar terisolasi menuju keteraturan spasial di dalam RAM

💡 Dilema Variabel Skalar

Jika kita harus mengolah nilai ujian 1.000 mahasiswa, menciptakan 1.000 variabel (nilai1, nilai2, ..., nilai1000) adalah kekacauan arsitektur: tidak dapat di-looping, boros kode, dan mustahil di-skalakan.

Array (Larik) mengumpulkan data dengan tipe seragam (*homogeneous*) ke dalam satu nama wadah bersama dengan pengalamatan indeks numerik yang elegan.

🏛️ Mukjizat Alokasi Kontigu (Contiguous Memory)

Elemen array disimpan secara bersebelahan tanpa celah di RAM. Ini memungkinkan prosesor menghitung alamat memori elemen ke-i hanya dengan matematika offset instan berkecepatan O(1)!

🧠 MODEL MEMORI FISIK

Anatomi Alokasi Kontigu & Rumus Alamat

Rahasia kecepatan akses O(1) di balik representasi fisik bus data RAM

Rumus Offset Alamat Memori:

Address(A[i]) = Base_Address + (i × Element_Size)

Mengapa indeks dimulai dari 0? Karena elemen pertama berada persis di alamat dasar (*Offset = 0*).

Visualisasi Array `int A[5]` (4 Bytes per elemen):

[0x1000] : A[0] = 85 (Base Address)
[0x1004] : A[1] = 90 (0x1000 + 1×4)
[0x1008] : A[2] = 78 (0x1000 + 2×4)
[0x100C] : A[3] = 92 (0x1000 + 3×4)
[0x1010] : A[4] = 88 (0x1000 + 4×4)
✍️ SINTAKSIS & DEKLARASI

Deklarasi, Inisialisasi & Kapasitas Tetap

Array tradisional bersifat statis (*Fixed-Size*) yang dialokasikan di Stack

Aturan Baku Array Statis:

  • Ukuran kapasitas wajib bertipe konstanta integer positif.
  • Elemen yang tidak diinisialisasi otomatis bernilai 0 (jika statis/global) atau bernilai sampah (*garbage* jika lokal di C++).
  • Total Memori = N × sizeof(Tipe_Data).
// 1. Deklarasi tanpa inisialisasi awal (ukuran 5)
int nilai[5];

// 2. Deklarasi langsung dengan inisialisasi
double ipk[4] = {3.5, 3.8, 3.2, 4.0};

// 3. Menentukan ukuran otomatis dari elemen
char huruf[] = {'U', 'U', 'I'}; // Otomatis size 3

// 4. Mengakses & Mengubah elemen:
nilai[0] = 90; // Mengisi indeks 0
cout << nilai[0]; // Membaca indeks 0
⚙️ OPERASI FUNDAMENTAL

Operasi Baku pada Struktur Data Larik

Analisis kompleksitas waktu dari berbagai manipulasi elemen array

Operasi Mekanisme Kerja Kompleksitas Waktu
Akses Acak (*Random Access*) Membaca atau menulis elemen A[i] secara langsung via rumus offset memori O(1) - Instan
Traversal (Penjelajahan) Mengunjungi seluruh elemen satu per satu dari indeks 0 s.d. N-1 dengan loop O(n) - Linear
Pencarian Linear (*Search*) Memindai larik untuk menemukan elemen target atau mencari min/max O(n) - Linear
Penyisipan / Penghapusan Memerlukan pergeseran (*shifting*) seluruh elemen di sebelah kanannya O(n) - Mahal

⚡ C++ (Manual Traversal)
#include <iostream>
using namespace std;

int main() {
    double data[5] = {82.5, 90.0, 68.5, 95.0, 77.5};
    double total = 0, nMin = data[0], nMax = data[0];

    for (int i = 0; i < 5; i++) {
        total += data[i];
        if (data[i] > nMax) nMax = data[i];
        if (data[i] < nMin) nMin = data[i];
    }
    cout << "Rata = " << total/5 << "\n";
    cout << "Max  = " << nMax << " | Min = " << nMin;
    return 0;
}
⚠️ ANOMALI & KERUSAKAN MEMORI

Jebakan Klasik Array: *Out of Bounds Error*

Ketika program mencoba mengakses alamat di luar batas blok kontigu

1. Segmentation Fault

Membaca atau menulis A[5] pada array berukuran 5 (indeks sah hanya 0..4). Di C++, ini mengakses memori ilegal!

2. Buffer Overflow Vulnerability

Eksploitasi keamanan siber paling terkenal: data yang meluap menimpa memori proses lain atau register kembalian (*return address*).

3. Ukuran Statis Kaku

Ukuran array tidak dapat diperbesar atau diperkecil saat runtime. Terlalu besar boros RAM, terlalu kecil memicu luapan.

🛡️ REKAYASA KODE BERSIH

Modern Traversal: *Range-Based For Loop*

Sintaksis modern C++11 & Python untuk mencegah *Off-by-One Index Error*

⚠️ Gaya Lama Berbahaya (Manual Indexing):
// Rawan salah batas: i <= 5 (Crash!)
int skor[5] = {10, 20, 30, 40, 50};

for (int i = 0; i <= 5; i++) {
    cout << skor[i] << " ";
}
✅ Gaya Modern Aman (Range-Based Loop):
// Kompilator otomatis menjamin batas aman:
int skor[5] = {10, 20, 30, 40, 50};

for (int x : skor) {
    cout << x << " "; // 10 20 30 40 50
}

// Di Python:
for x in skor:
    print(x)
