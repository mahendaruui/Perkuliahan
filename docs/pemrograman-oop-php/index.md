## 📚 Daftar Isi & Silabus Perkuliahan

### 1. Fondasi Paradigma & Objek
- [Rencana Pembelajaran Semester (RPS)](/pemrograman-oop-php/RPS) — *Rencana perkuliahan, CPL, CPMK, dan sistem penilaian.*
- [Minggu 1: Pengantar Paradigma OOP & Ekosistem PHP 8+](/pemrograman-oop-php/pengantar-oop) — *Evolusi paradigma, perbandingan prosedural vs OOP, dan 4 pilar fundamental.*
- [Minggu 2: Class, Objek, dan Manajemen Memori](/pemrograman-oop-php/class-dan-object) — *Pemodelan entitas, typed properties, operator `->`, `$this`, dan object cloning.*
- [Minggu 3: Method, Constructor Promotion, dan Siklus Hidup Objek](/pemrograman-oop-php/constructor-method) — *Constructor property promotion, named arguments, destructors, dan static factory methods.*

### 2. Empat Pilar Utama Pemrograman Berorientasi Objek
- [Minggu 4: Enkapsulasi, Visibility Modifiers, dan Readonly](/pemrograman-oop-php/encapsulation) — *Information hiding, state invariant, Tell Don't Ask, readonly properties (PHP 8.1+), dan hooks (PHP 8.4+).*
- [Minggu 5: Pewarisan (Inheritance) dan Komposisi Trait](/pemrograman-oop-php/inheritance) — *Taksonomi Is-A, mitigasi fragile base class, final keyword, dan horizontal code reuse via Trait.*
- [Minggu 6: Polimorfisme (Polymorphism) & Dynamic Dispatch](/pemrograman-oop-php/polymorphism) — *Klasifikasi Cardelli-Wegner, polymorphic type hinting, polymorphic collections, dan engine notification.*
- [Minggu 7: Abstraksi, Interface, dan Backed Enum](/pemrograman-oop-php/interface-abstract) — *Template method pattern, multiple interfaces, dan integrasi Backed Enum PHP 8.1+.*

### 3. Evaluasi Tengah Semester
- **Minggu 8: Ujian Tengah Semester (UTS)** — *Evaluasi Teoretis dan Uji Praktikum Komprehensif Minggu 1–7.*

### 4. Ekosistem Modern, Error Handling & I/O
- [Minggu 9: Manajemen Namespace, Standar PSR-4, dan Composer](/pemrograman-oop-php/namespace) — *namespace isolation, resolusi FQN/aliasing, PSR-4 autoloading, dan optimasi class produksi.*
- [Minggu 10: Penanganan Kesalahan (Exception Handling) & Robust Error Flow](/pemrograman-oop-php/exception-handling) — *Hierarki Throwable, fail-fast, multi-catch, throw expression PHP 8.0+, dan rich exceptions.*
- [Minggu 11: Koleksi Objek (Object Collections) & Manipulasi Array Modern](/pemrograman-oop-php/collection) — *First-Class Collections, SPL interfaces (Countable, IteratorAggregate), dan manipulasi fungsional.*
- [Minggu 12: Manajemen Berkas (File Handling & I/O Streams)](/pemrograman-oop-php/file-handling) — *File locking (flock LOCK_EX), SplFileObject, json_validate (PHP 8.3+), dan File Repository.*

### 5. Prinsip Desain & Arsitektur Aplikasi
- [Minggu 13: Prinsip Desain Perangkat Lunak SOLID di PHP 8+](/pemrograman-oop-php/solid-principle) — *Mitigasi software rot, bedah 5 pilar SOLID, dan Constructor Dependency Injection.*
- [Minggu 14: Arsitektur Aplikasi Berorientasi Objek (Model-Service-Repository)](/pemrograman-oop-php/aplikasi-oop) — *Clean Architecture, 4 lapisan konsentris, Dependency Rule, dan studi kasus Perpustakaan.*
- [Minggu 15: Capstone Mini Project — Sistem Point of Sale (POS) Terpadu](/pemrograman-oop-php/mini-project) — *Sintesis 14 bab materi, integrasi Strategy Pattern, keranjang First-Class, dan rubrik penilaian.*
- [Minggu 16: Evaluasi Akhir Semester & Presentasi Proyek](/pemrograman-oop-php/evaluasi-akhir) — *Demonstrasi perangkat lunak, code review, dan laporan akhir capstone.*
