# Minggu 15: Mini Project OOP PHP

## 🎯 Capaian Pembelajaran (Sub-CPMK 6)
Setelah menyelesaikan materi ini, mahasiswa mampu:
1. Menyusun proyek perangkat lunak berbasis OOP PHP.
2. Menerapkan minimal 4 pilar OOP, Collection, Exception, dan File I/O.

---

## 📋 Kriteria Wajib Proyek

- **OOP:** Class, Objek, 4 Pilar OOP.
- **Pewarisan:** Minimal 1 Abstract Class/Interface dengan 2 Subclass.
- **Collection:** Array terstruktur / Object Collection.
- **Exception Handling:** `try-catch` + minimal 1 Custom Exception.
- **File I/O:** Persistensi data ke JSON atau CSV.
- **Autoloading:** Namespace + Composer PSR-4.

---

## 💡 Pilihan Topik

### Topik 1: Sistem Kasir & POS Toko Retail
Inventaris barang (Makanan, Elektronik, Pakaian), transaksi kasir, diskon member, struk belanja, riwayat transaksi simpan ke JSON.

### Topik 2: Sistem Reservasi Hotel
Kamar (Standard, Deluxe, Suite), pemesanan tamu, check-in/check-out, kalkulasi biaya, cetak bukti reservasi.

### Topik 3: Sistem Rekam Medis Klinik
Pendaftaran pasien (Umum, BPJS, Asuransi), antrian poli, resep obat, riwayat diagnosa.

### Topik 4: Sistem Rental Kendaraan
Rental mobil/motor/bus, tarif harian, denda keterlambatan, laporan pendapatan.
