# Minggu 16: Evaluasi Akhir Semester & Presentasi Proyek

## 🎯 Capaian Pembelajaran (Sub-CPMK 6)
Setelah menyelesaikan evaluasi ini, mahasiswa mampu:
1. Mempresentasikan hasil pengembangan aplikasi OOP PHP secara komprehensif.
2. Mendemonstrasikan fungsionalitas sistem secara langsung (*live demo*).
3. Menyusun dokumentasi teknis dan laporan akhir proyek.

---

## 🎤 Format Presentasi
- **Durasi:** 10 menit presentasi + 5 menit tanya jawab.
- **Media:** Slide presentasi & source code aktif di IDE/terminal.

---

## 📑 Struktur Slide
1. **Judul:** Nama Sistem, Anggota & NIM.
2. **Latar Belakang:** Masalah yang diselesaikan.
3. **UML Class Diagram.**
4. **Penerapan 4 Pilar OOP** — Di mana Encapsulation, Inheritance, Polymorphism, Abstraction diterapkan.
5. **Fitur:** Exception Handling, Collection, File I/O, Namespace.
6. **Live Demo.**
7. **Kesimpulan & Saran.**

---

## 📊 Rubrik Penilaian (UAS - Bobot 25%)

| Kriteria | Bobot | Deskripsi |
| :--- | :---: | :--- |
| **Penerapan OOP** | 30% | Encapsulation, Inheritance, Polymorphism, Abstraction |
| **Kualitas Kode** | 20% | Namespace rapi, penamaan PSR, clean code |
| **Error Handling** | 15% | try-catch, custom exception, tidak crash |
| **Fitur & File I/O** | 15% | Fungsionalitas lengkap, data persisten |
| **Presentasi** | 20% | Penjelasan logika, jawab pertanyaan teknis |

---

## 📦 Berkas Dikumpulkan
1. **Link Repository GitHub** (source code + README.md).
2. **Laporan Proyek (PDF)** — class diagram, screenshot aplikasi.
3. **File Slide Presentasi (PDF/PPTX).**
