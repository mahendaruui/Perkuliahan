# Algoritma dan Pemrograman (IFR206)

Selamat datang di repositori perkuliahan **Algoritma dan Pemrograman** (Kode MK: **IFR206**, Bobot: **3 SKS**)! 

Modul materi perkuliahan ini dirancang secara komprehensif berbasis kurikulum **Outcome-Based Education (OBE)** Program Studi Informatika, Fakultas Sains dan Teknologi, Universitas Ubudiyah Indonesia (UUI).

## 💡 Metode Pembelajaran & Praktikum Laboratorium

Perkuliahan memadukan tiga pilar aktivitas utama:
1. **Interactive Lecture & Conceptual Review:** Pendalaman logika matematis dan trace table alur eksekusi algoritma.
2. **Hands-on Laboratory Coding:** Implementasi langsung di lingkungan IDE modern dengan pengujian test cases mandiri.
3. **Problem-Based Mini Project:** Penyelesaian kasus komputasi terpadu yang memupuk kerja tim, kemandirian, dan etika penulisan kode bersih (*clean code*).
