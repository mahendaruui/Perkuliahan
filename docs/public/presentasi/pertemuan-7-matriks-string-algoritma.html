🧠 MODEL MEMORI FISIK

Pemetaan Matriks 2D ke RAM Linear (Row-Major)

RAM berbentuk linier 1D: Bagaimana koordinat 2D diratakan (*flattened*) oleh hardware?

Rumus Alamat Row-Major Order:

Address(M[i][j]) = Base + ((i × COLS) + j) × Size

Baris ke-0 disimpan seluruhnya terlebih dahulu, lalu disambung oleh Baris ke-1, Baris ke-2, dst secara kontigu.

Visualisasi Matriks 2×3 di RAM:

[0x1000] : M[0][0] = 1 (Base)
[0x1004] : M[0][1] = 2
[0x1008] : M[0][2] = 3
[0x100C] : M[1][0] = 4 (Mulai Baris Baru)
[0x1010] : M[1][1] = 5
[0x1014] : M[1][2] = 6

➕ ALDIJABAR MATRIKS

Operasi Penjumlahan & Perkalian Matriks

Transformasi aljabar linier dalam algoritma komputasi bertingkat

1. Penjumlahan Matriks `C[i][j] = A[i][j] + B[i][j]`

Syarat: Ordo harus sama persis ($m imes n$). Kompleksitas: O(m × n).

for (int i = 0; i < M; i++) {
    for (int j = 0; j < N; j++) {
        C[i][j] = A[i][j] + B[i][j];
    }
}

2. Perkalian Matriks (Dot Product 3 Loop)

Syarat: Kolom A = Baris B. Kompleksitas: O(m × k × n).

for (int i = 0; i < M; i++) {
    for (int j = 0; j < N; j++) {
        C[i][j] = 0;
        for (int k = 0; k < K; k++) {
            C[i][j] += A[i][k] * B[k][j];
        }
    }
}

💻 STUDI KASUS PRAKTIKUM

Studi Kasus: Algoritma Pengujian Palindrom

Menggunakan *Two-Pointer Technique* berkecepatan O(n) tanpa alokasi memori tambahan O(1)

🐍 Python 3 (Two Pointer & Slicing)
def is_palindrom(teks):
    teks = teks.lower().replace(" ", "")
    # Cara 1: Slicing Python
    return teks == teks[::-1]

kata = input("Masukkan kata: ")
print("Palindrom!" if is_palindrom(kata) else "Bukan!")
⚡ C++ (Two-Pointer In-Place)
#include <iostream>
#include <string>
using namespace std;

bool cekPalindrom(string s) {
    int kiri = 0, kanan = s.length() - 1;
    while (kiri < kanan) {
        if (s[kiri] != s[kanan]) return false;
        kiri++; kanan--;
    }
    return true;
}
⚠️ ANOMALI & PERFORMA HARDWARE

Jebakan Klasik Matriks: Penalti Cache Miss

Mengapa urutan loop `[i][j]` vs `[j][i]` bisa membuat program 10x lebih lambat?

✅ Akses Row-Major (Cache-Friendly - Cepat):

// Loop Luar: i (Baris), Loop Dalam: j (Kolom)
for (int i = 0; i < N; i++) {
    for (int j = 0; j < N; j++) {
        sum += M[i][j]; // Cache Hit 99%!
    }
}

Data bersebelahan sudah tersimpan di L1/L2 Cache CPU (Sangat Cepat!).

❌ Akses Column-Major (Cache Thrashing - Lambat):

// Loop Luar: j (Kolom), Loop Dalam: i (Baris)
for (int j = 0; j < N; j++) {
    for (int i = 0; i < N; i++) {
        sum += M[i][j]; // Cache Miss Parah!
    }
}

CPU dipaksa melompat-lompat ribuan byte di RAM fisik (Sangat Lambat!).
