🗂️ Dua Tingkat Fungsi

Figure-level vs Axes-level

Pilih sesuai kebutuhan: eksplorasi cepat atau kontrol presisi:

🚀 FIGURE-LEVEL
Mengelola seluruh kanvas sekaligus (FacetGrid):
• displot() → distribusi
• catplot() → komparasi kategori
• relplot() → relasi & tren

Cocok untuk eksplorasi cepat multi-panel.
⚙️ AXES-LEVEL
Menggambar langsung pada objek ax (dari Matplotlib):
• histplot(), kdeplot(), ecdfplot()
• boxplot(), violinplot(), barplot()
• scatterplot(), lineplot()

Fleksibel digabung ke plt.subplots().
💡 Aturan praktis: eksplorasi awal → Figure-level. Dashboard final & kustomisasi Tufte → Axes-level di dalam plt.subplots().
🐼 Integrasi Data

Seaborn + Pandas DataFrame

Kekuatan Seaborn: bicara dalam bahasa kolom, bukan array mentah:

import seaborn as sns
import matplotlib.pyplot as plt
sns.set_theme(style="ticks", palette="muted")

tips = sns.load_dataset("tips")

# Bicara dengan NAMA KOLOM (bukan array)
sns.histplot(
    data=tips, x="total_bill",
    hue="time"          # pisah per kategori
)
🔗 Jembatan ke P4
Seaborn WAJIB menerima Tidy Data (1 baris = 1 observasi). Di sinilah melt() dan pivot_table() dari Pertemuan 4 berperan sebelum plotting.
✅ Parameter data=, x=, y=, hue= memetakan langsung ke nama kolom DataFrame.

📊 Univariat • 1

Histogram + KDE

Estimasi kepadatan probabilitas untuk melihat modus, skewness, & kurtosis:

fig, ax = plt.subplots(figsize=(9, 5))

sns.histplot(
    data=tips, x="total_bill",
    kde=True, bins=20,
    color="#0284c7", ax=ax
)

# Rug plot: tunjukkan titik observasi asli
sns.rugplot(data=tips, x="total_bill",
            height=0.08, ax=ax)
Bentuk kurva (bimodal / miring)
⚠️ Kelemahan: Histogram sensitif terhadap lebar bin (bins) dan bandwidth KDE. Ubah nilai bin, bentuk kurva bisa berubah.
📉 Univariat • 2

ECDF Plot

Empirical Cumulative Distribution Function — bebas 100% dari bias binning:

fig, ax = plt.subplots(figsize=(9, 5))

sns.ecdfplot(
    data=tips, x="total_bill",
    hue="time",
    palette={"Lunch": "#0d9488",
             "Dinner": "#e11d48"},
    linewidth=2.2, ax=ax
)

# Garis bantu median (50%)
ax.axhline(0.5, color='#94a3b8',
           linestyle=':')
Kurva kumulatif (0% → 100%)
✅ Keunggulan: tidak ada artefak binning. Membaca persentil langsung: "50% tagihan di bawah nilai X". Sangat jujur untuk perbandingan distribusi.

📦 Komparasi • 1

Box Plot (Tukey)

Ringkasan 5 angka: Min, Q1, Median, Q3, Max (+ pencilan):

📐 5 Angka Statistik
• Q1 — kuartil bawah (25%)
• Median — garis tengah kotak
• Q3 — kuartil atas (75%)
• Whisker — 1.5×IQR (kaitan P4!)
• Titik di luar whisker — pencilan
✅ Efisien: bandingkan 10+ kategori sekaligus dalam satu bidang.
❌ Batasan kritis
Box plot menyembunyikan distribusi bimodal. Data dengan dua puncak bisa terlihat seperti distribusi seragam yang membosankan. Jangan hanya percaya kotak!
sns.boxplot(data=tips, x="day",
            y="total_bill",
            hue="smoker", ax=ax)
⚠️ Jembatan P4: whisker box plot adalah batas Tukey (Q1 − 1.5×IQR s.d. Q3 + 1.5×IQR) yang sama dengan metode deteksi outlier IQR.
🎻 Komparasi • 2

Violin Plot

Box plot + kontur kepadatan KDE — mengungkap bimodalitas:

sns.violinplot(
    data=tips, x="day", y="total_bill",
    hue="smoker", split=True,
    inner="quart", cut=0,
    palette={"Yes": "#38bdf8",
             "No": "#fb7185"}, ax=ax
)

# Tambah titik data asli (transparansi)
sns.stripplot(data=tips, x="day",
             y="total_bill",
             hue="smoker", dodge=True,
             alpha=0.35, jitter=0.15, ax=ax)
🎯 Keunggulan
Menampilkan bentuk kepadatan penuh: bimodal, ekor panjang, dan celah data yang tersembunyi di box plot. Parameter split=True membandingkan dua grup dalam satu violin.
⚠️ Hati-hati: parameter smoothing dapat menciptakan ekor semu (data yang tidak ada). Gunakan cut=0 agar violin tidak melebihi rentang data riil.
🐝 Komparasi • 3

Boxen & Swarm: Sesuai Ukuran Sampel

Jumlah observasi menentukan pilihan — bukan selera:

N BESAR (> 10.000)
Boxen / Letter-Value Plot
Menampilkan kuantil ekstrem secara detail, jauh lebih informatif dari box plot biasa untuk data masif. Setiap "huruf" mewakili kuantil pada kedalaman yang berbeda.
N KECIL (< 100)
Swarm / Strip Plot
Menampilkan seluruh titik observasi asli tanpa tumpang tindih (swarm mengatur posisi otomatis). Transparansi penuh — audiens melihat setiap data, bukan ringkasan.
💡 Kombinasi favorit: Violin + Stripplot. Kontur KDE untuk bentuk distribusi, titik jitter untuk membuktikan kepadatan sampel nyata.

🧩 Multi-Kondisi

FacetGrid & Figure-level

Pecah grafik per kategori — Small Multiples versi Seaborn (kaitan P3!):

# Figure-level: otomatis jadi grid
sns.displot(
    data=penguins, x="body_mass_g",
    col="island",   # panel per pulau
    hue="sex",      # warna per jenis kelamin
    kind="kde", fill=True
)

# Atau kontrol manual dengan FacetGrid
g = sns.FacetGrid(penguins, col="island")
g.map_dataframe(sns.histplot,
    x="body_mass_g", kde=True)
🎯 Parameter kunci
• col= — panel per kategori (kolom).
• row= — panel per kategori (baris).
• hue= — warna per sub-kategori.
• kind= — jenis plot (hist/kde/ecdf).
💡 Kaitan P3: FacetGrid adalah implementasi Small Multiples. Skala sumbu otomatis seragam bila sharex/sharey diaktifkan.
📏 Estimasi Statistik

Bootstrap Confidence Interval

Error bar Seaborn = 95% CI hasil resampling, bukan standar deviasi:

sns.barplot(
    data=tips, x="day", y="tip",
    hue="sex", palette="Blues",
    errorbar=('ci', 95),   # 95% CI
    capsize=0.1,
    err_kws={'linewidth': 1.5,
             'color': '#1e293b'},
    ax=ax
)
🔁 Cara kerja Bootstrap
Seaborn mengambil ribuan resample acak dari data, menghitung rata-rata tiap resample, lalu mengambil rentang 2.5%–97.5% sebagai interval kepercayaan 95%.
⚠️ Jangan salah tafsir: error bar ini bukan standar deviasi. Ia menunjukkan ketidakpastian estimasi rata-rata, bukan sebaran data mentah.
💻 Hands-on

Tiga Praktikum Seaborn

Dari distribusi univariat sampai estimasi statistik:

1
Distribusi Univariat

histplot(kde=True) + rugplot() di panel kiri; ecdfplot(hue='time') di panel kanan. Membandingkan bentuk vs kumulatif.

2
Komparasi Kategorikal

violinplot(split=True, inner='quart') + stripplot(dodge=True, jitter=0.15) — melihat distribusi pengeluaran per hari & status merokok.

3
Estimasi dengan CI 95%

barplot(errorbar=('ci',95), capsize=0.1) — rata-rata tip per hari & gender beserta interval kepercayaannya.

🎮 Refleksi Kritis

Kuis Kilat 3 Menit

Jawab dulu, lalu klik untuk membuka jawaban:

❓ 1. Kapan memakai ECDF dibanding histogram?
✅ Saat ingin membandingkan distribusi tanpa bias lebar bin. ECDF membaca persentil langsung (mis. "50% data di bawah X") dan tidak berubah-ubah saat bin diatur.
❓ 2. Kenapa box plot bisa menyesatkan pada data bimodal?
✅ Karena box plot hanya meringkas 5 angka. Dua puncak distribusi (bimodal) bisa terlihat seperti satu distribusi seragam. Solusi: gunakan violin plot untuk melihat kontur kepadatan.
❓ 3. Apa arti error bar pada sns.barplot(errorbar=('ci',95))?
✅ Interval kepercayaan 95% hasil bootstrap resampling untuk estimasi rata-rata — bukan standar deviasi sampel. Ia mengukur ketidakpastian estimasi, bukan sebaran data.
