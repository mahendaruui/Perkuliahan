🛠️ Siklus Hidup Objek

Mengapa Kita Membutuhkan Constructor?

Menjamin setiap objek yang lahir langsung memiliki data valid (*Initialized State*):

❌ TANPA CONSTRUCTOR (RAWAN ERROR) 
$rek = new RekeningBank();
// Developer lupa mengisi properti penting:
// $rek->nomorRekening = ...
// $rek->saldo = ...

// 💥 Objek lahir dalam kondisi kosong/rusak
$rek->transfer(50000);
✅ DENGAN CONSTRUCTOR (WAJIB ISI) 
// Constructor MEMAKSA pengisian data wajib
$rek = new RekeningBank(
    nomorRekening: "123-456",
    pemilik: "Budi Santoso",
    saldoAwal: 500_000
);

// 🌟 Objek dijamin 100% siap pakai
🚀 PHP 8.0 Super Feature

Constructor Property Promotion

Mengurangi 70% baris kode boilerplate deklarasi properti di PHP:

PHP 5 / 7 (Cara Klasik - 16 Baris)
class User {
    public string $id;
    public string $nama;
    public string $email;

    public function __construct(
        string $id,
        string $nama,
        string $email
    ) {
        $this->id = $id;
        $this->nama = $nama;
        $this->email = $email;
    }
}
PHP 8+ (Constructor Promotion - 7 Baris!)
class User {
    public function __construct(
        public readonly string $id,
        public string $nama,
        public string $email
    ) {}
}

// PHP otomatis membuat properti
// dan mengisinya saat instansiasi!
🎯 Sintaks Modern

Named Arguments & Default Values

Sebutkan nama argumen saat memanggil method/constructor tanpa terikat urutan:

class Produk {
    public function __construct(
        public string $nama,
        public float $harga,
        public int $stok = 0,
        public string $kategori = "Umum"
    ) {}
}

// Named Arguments: Urutan bebas dan parameter default bisa dilewati!
$p = new Produk(
    kategori: "Elektronik",
    harga: 12_500_000,
    nama: "Monitor LG 27 Inch"
    // $stok otomatis menggunakan default (0)
);
🧹 Lifecycle Cleanup

Destructor: __destruct()

Method yang otomatis dipanggil saat objek dihancurkan atau memori dibersihkan:

class KoneksiDatabase {
    public function __construct(
        private string $host
    ) {
        echo "🔌 Koneksi ke {$this->host} dibuka.\n";
    }

    public function __destruct() {
        echo "🔒 Koneksi ke {$this->host} ditutup.\n";
    }
}

$db = new KoneksiDatabase("localhost:3306");
// ... transaksi query berlangsung ...
// Saat script PHP selesai, destructor otomatis jalan!
Kegunaan Umum Destructor:
• Penutupan Koneksi Database: Mencegah connection leak di server.
• File Stream: Menutup handle file (fclose()) secara aman.
• Audit Log: Mencatat durasi eksekusi atau transaksi ke file log.
• Pembersihan Cache: Menghapus file sementara di disk.
🛡️ Strict Type System

Type Declarations & Union Types

Menjamin integritas data parameter method dan return value:

declare(strict_types=1);

class KalkulatorKeuangan {
    // Union Type (int|float): Menerima bilangan bulat ATAU desimal
    public function hitungPajak(int|float $nominal, float $persen): float {
        return $nominal * ($persen / 100);
    }

    // Nullable Type (?string): Boleh mengembalikan string ATAU null
    public function cariKodePromo(string $kode): ?string {
        return ($kode === "DISKON50") ? "Potongan 50%" : null;
    }
}
⚡ Level Class vs Level Objek

Static Properties & Static Methods

Member yang terikat pada Class secara global tanpa perlu new:

class KursValuta {
    // Static Property
    public static float $kursUsd = 16_200.0;

    // Static Method
    public static function usdKeIdr(float $usd): float {
        // Gunakan self::$ untuk akses static
        return $usd * self::$kursUsd;
    }
}

// Panggil langsung tanpa new!
echo KursValuta::usdKeIdr(100); // Rp 1.620.000
Perbedaan Kunci: $this-> vs self::
• $this-> (Instance Level): Merujuk ke objek aktif spesifik (beda objek, beda data).

• self:: (Class Level): Merujuk ke definisi Class (satu nilai dipakai bersama oleh seluruh aplikasi).
🏭 Design Pattern

Pola Static Factory Method

Solusi standar industri untuk variasi pembuatan objek di PHP:

class User {
    // Constructor private agar instansiasi hanya lewat Factory
    private function __construct(
        public string $username,
        public string $role,
        public float $saldoLimit
    ) {}

    // Factory Method 1: Member Standar
    public static function createRegular(string $username): self {
        return new self($username, "Regular", 1_000_000);
    }

    // Factory Method 2: Akun VIP
    public static function createVIP(string $username): self {
        return new self($username, "VIP Gold", 50_000_000);
    }
}

$userBiasa = User::createRegular("budi99");
$userSultan = User::createVIP("sultan_aceh");
