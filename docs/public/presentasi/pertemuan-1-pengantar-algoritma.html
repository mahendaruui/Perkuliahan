📖 Definisi Formal

Apa itu Algoritma?

Sekumpulan instruksi yang terstruktur, logis, terurut, berhingga, dan tidak bermakna ganda:

📥 INPUT

Data masukan berdefinisi jelas (nol atau lebih nilai)

→
⚙️ PROSES

Langkah terurut, deterministik & berhingga

→
📤 OUTPUT

Solusi benar & dapat diverifikasi

🍳 Analogi Resep
Bahan = input, langkah memasak = proses, hidangan = output. Resep "garam secukupnya" = bukan algoritma (ambigu!).
🧮 Analogi Rumus
BMI = kg ÷ m²: input terukur, langkah eksak, output tunggal yang bisa dicek ulang siapa pun.
🚫 Bukan Algoritma
"Goreng hingga harum" — kapan harum? bagi siapa? Tidak berhingga ukurannya, tidak definitif.

✋ Standar Donald Knuth

5 Karakteristik Fundamental

Tes kelayakan: prosedur yang gagal satu saja = bukan algoritma:

📥
1. Finiteness
Wajib berhenti setelah langkah berhingga. Anti infinite loop.
🎯
2. Definiteness
Tiap instruksi satu tafsir. Nol ambiguitas.
📦
3. Input
Nol/lebih masukan berdomain presisi.
📤
4. Output
Minimal satu keluaran terkait input.
⚡
5. Effectiveness
Tiap langkah realistis dikerjakan mesin (ALU).
🧪
Uji di UTS
Diberi prosedur → tentukan karakteristik mana yang dilanggar + alasannya.
05
✋ Bedah Knuth • 1

Finiteness & Definiteness

Dua pelanggaran paling sering muncul di kode mahasiswa:

FINITENESS — HARUS BERHENTI
Tiap loop & rekursi wajib punya exit condition.

❌ while(true){...} tanpa break → hang, freeze, Out of Memory.
✅ Counter + batas + kondisi keluar yang terbukti tercapai.
DEFINITENESS — SATU TAFSIR
Hindari "secukupnya", "hingga harum", pembagi nol.

❌ "Masukkan garam secukupnya" → tiap orang beda hasil.
✅ "Masukkan garam 5 gram" → deterministik, terverifikasi.
⚠️ Contoh tugas 1: resep "goreng bumbu hingga harum" melanggar definiteness. Perbaikan: "goreng bumbu 3 menit pada api sedang hingga suhu 120°C".
06
✋ Bedah Knuth • 2

Input, Output & Effectiveness

Tiga penopang agar algoritma berguna dan bisa dijalankan mesin nyata:

📦
Input Presisi
Domain & tipe eksplisit, mis. x ∈ ℝ, x ≥ 0. Tanpa ini: unexpected behavior saat data anomali masuk.
📤
Output Terjamin
Ada return value / perubahan status. Tanpa output = prosedur tanpa manfaat fungsional.
⚡
Effectiveness
Operasi dasar yang bisa dihitung ALU secara eksak. "Pikirkan angka beruntung" bukan instruksi mesin!
Jika DilanggarDampak Nyata
Tanpa terminasi (finiteness)Hang, freeze, Out of Memory
Instruksi ambigu (definiteness)Hasil inkonsisten / runtime crash
Input tak terdefinisiPerilaku liar saat data aneh
Tanpa outputAlgoritma sia-sia
Langkah tak realistisTidak bisa dieksekusi mesin fisik

🅿️ Studi Kasus

Flowchart: Tarif Parkir

Aturan: ≤ 2 jam = Rp 5.000, selebihnya + Rp 3.000/jam. Ikuti alurnya:

🟢 MULAI
↓
Input: Jam_Masuk, Jam_Keluar
↓
Durasi = Keluar − Masuk
↓
Durasi ≤ 2 jam?
↓
YA →
Biaya = 5000
TIDAK →
5000 + (Durasi−2)×3000
↓
Tampilkan Biaya
↓
🔴 SELESAI
🔎 Bedah alur
• Oval membuka & menutup.
• Jajaran genjang untuk I/O.
• Persegi untuk hitungan.
• Belah ketupat satu-satunya titik cabang.
💡 Trace cepat: masuk 08, keluar 11 → durasi 3 → TIDAK → 5000 + 1×3000 = Rp 8.000. Coba masuk 09 keluar 10!

📝 Notasi Teks Formal

Pseudocode 3 Blok

Algoritma parkir yang sama, ditulis untuk dibaca manusia — tanpa sintaks kaku:

PROGRAM HitungTarifParkir
{ Menghitung biaya parkir kendaraan }

DEKLARASI:
    jamMasuk, jamKeluar : integer
    durasi, biayaTotal  : integer

ALGORITMA:
    read(jamMasuk, jamKeluar)
    durasi <- jamKeluar - jamMasuk
    if durasi <= 2 then
        biayaTotal <- 5000
    else
        biayaTotal <- 5000 + (durasi - 2) * 3000
    endif
    write("Biaya: Rp ", biayaTotal)
📏 Aturan blok
• PROGRAM — nama + deskripsi.
• DEKLARASI — variabel + tipe.
• ALGORITMA — langkah dengan read/write/if/endif, assignment <-.
✅ Kenapa dua notasi? Flowchart menangkap struktur cabang sekilas; pseudocode menangkap detail hitungan. Profesional memakai keduanya.

⚔️ Dual-Stack

Konversi Suhu: C++ vs Python

Satu algoritma (dengan validasi nol mutlak), dua bahasa:

// C++ — ketat & eksplisit
#include <iostream>
int main() {
    double celcius;
    std::cin >> celcius;
    if (celcius < -273.15) {
        std::cerr << "[ERROR] Nol mutlak!";
        return 1;
    }
    double f = (9.0/5.0*celcius)+32.0;
    double k = celcius + 273.15;
    std::cout << f << " F, " << k << " K";
}
# Python — ringkas & ekspresif
celcius = float(input("Celcius: "))
if celcius < -273.15:
    print("[ERROR] Nol mutlak!")
    exit(1)

f = (9.0/5.0*celcius)+32.0
k = celcius + 273.15
print(f"{f:.2f} F, {k:.2f} K")
Input: 100 → 212.00 F, 373.15 K
