💡 Definisi Formal Algoritma

"Algoritma adalah urutan langkah-langkah logis, teratur, dan terbatas yang disusun secara sistematis untuk memproses masukan (input) menjadi keluaran (output) yang menyelesaikan suatu permasalahan komputasi."

🔍 KARAKTERISTIK FORMAL

5 Karakteristik Algoritma (Donald Knuth)

Syarat mutlak agar suatu prosedur sah disebut algoritma

1. Input (Masukan)

Memiliki nol atau lebih nilai yang diberikan sebelum algoritma dieksekusi.

2. Output (Keluaran)

Wajib menghasilkan minimal satu solusi keluaran yang bermanfaat.

3. Definiteness (Kepastian)

Setiap instruksi harus jelas, eksplisit, dan tidak memiliki makna ganda (*non-ambiguous*).

4. Finiteness (Keterbatasan)

Algoritma wajib berhenti setelah mengeksekusi sejumlah langkah terhingga (tidak boleh infinite loop).

5. Effectiveness (Efektivitas)

Setiap langkah instruksi harus sederhana dan dapat dikerjakan oleh mesin dalam waktu yang wajar.

⚙️ RELASI & PERBEDAAN

Algoritma vs Program Komputer

Rumus Klasik Niklaus Wirth: Algorithms + Data Structures = Programs

📐 Algoritma

  • Cetak biru (*blueprint*) rancangan logika solusi.
  • Independen dari bahasa pemrograman apa pun.
  • Dianalisis melalui nalar manusia dan *trace table*.
  • Fokus pada efisiensi logika dan kebenaran alur.

💻 Program Komputer

  • Implementasi konkret dalam kode sumber (*source code*).
  • Terikat aturan sintaksis bahasa (Python, C++, Java, Go).
  • Diterjemahkan oleh Compiler/Interpreter & dieksekusi CPU.
  • Fokus pada manajemen memori dan interaksi sistem.
📊 NOTASI VISUAL

Diagram Alir (Flowchart Standar ISO 5807)

Simbol-simbol grafis internasional untuk memetakan alur instruksi

🔴 Terminator (Kapsul)

Menandai titik awal (Start / Mulai) dan titik akhir (End / Selesai) algoritma.

🔷 Input / Output (Jajar Genjang)

Operasi membaca data masukan dari user (`read`) atau menampilkan hasil ke layar (`print/write`).

⏹️ Process (Persegi Panjang)

Instruksi pemrosesan aritmatika, kalkulasi, manipulasi nilai variabel (`luas = p * l`).

🔶 Decision (Belah Ketupat)

Percabangan kondisional dengan dua jalur keluaran: Ya (True) atau Tidak (False).

➡️ Flowline (Garis Alir)

Menunjukkan arah urutan eksekusi langkah selanjutnya.

⭕ Connector (Lingkaran)

Penyambung alur diagram pada satu halaman agar tidak rumit berpotongan.

📝 NOTASI TEKSTUAL

Notasi Pseudocode Terstruktur

Struktur baku penyusunan algoritma dalam teks formal

1. Bagian Judul (Header)

Nama algoritma beserta penjelasan ringkas tujuannya.

2. Bagian Deklarasi

Mendefinisikan seluruh variabel dan tipe data yang digunakan.

3. Bagian Deskripsi / Badan

Langkah-langkah instruksi komputasi utama.

ALGORITMA HitungLuas
{ Menghitung luas persegi panjang }

DEKLARASI:
    panjang : real
    lebar   : real
    luas    : real

DESKRIPSI:
    read(panjang)
    read(lebar)
    luas <- panjang * lebar
    write("Luas = ", luas)

Studi Kasus: Cek Bilangan Genap / Ganjil

Perbandingan implementasi algoritma pada Python dan C++

🐍 Python 3
# Program Cek Genap Ganjil
bilangan = int(input("Masukkan angka: "))

if bilangan % 2 == 0:
    print(f"{bilangan} adalah GENAP")
else:
    print(f"{bilangan} adalah GANJIL")
⚡ C++
#include <iostream>
using namespace std;

int main() {
    int bilangan;
    cout << "Masukkan angka: ";
    cin >> bilangan;

    if (bilangan % 2 == 0) {
        cout << bilangan << " adalah GENAP\n";
    } else {
        cout << bilangan << " adalah GANJIL\n";
    }
    return 0;
}
