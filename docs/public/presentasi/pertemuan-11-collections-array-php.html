⚠️ MASALAH ARSITEKTUR

Tantangan: Bahaya Array Primitif Tanpa Enkapsulasi

Mengapa menggunakan array biasa untuk kumpulan entitas bisnis sering menimbulkan bug tersembunyi?

❌ Masalah 1: Ketiadaan Type Safety

Array PHP menerima tipe apa pun secara bebas. String atau integer dapat masuk tanpa sengaja ke daftar Mahasiswa:

$daftarMhs = []; $daftarMhs[] = new Mahasiswa("2301", "Ali"); $daftarMhs[] = "Bukan Objek Mahasiswa!"; // ⚠️ Lolos! foreach ($daftarMhs as $m) { echo $m->getNama(); // 💥 Fatal Error di Runtime }

❌ Masalah 2: Logika Bisnis Berceceran

Perhitungan total SKS, filter mahasiswa cumlaude, atau validasi duplikasi ditulis ulang di banyak controller (melanggar DRY).

// Logika kalkulasi ditulis manual berulang-ulang: $totalSks = 0; foreach ($krs as $mk) { $totalSks += $mk->sks; }
Aturan Object Calisthenics (Jeff Bay): "Rule #8: No classes with more than two instance variables, and Wrap all collections." Setiap class yang menampung kumpulan data jamak wajib dijadikan First-Class Collection!
💎 DESAIN BERSIH

Filosofi First-Class Collections

Membungkus array mentah ke dalam class khusus yang memiliki perilaku dan validasi domain sendiri.

📌 Ciri Khas First-Class Collection:

  • Satu-satunya Properti: Properti internal utamanya adalah array bertipe privat (private array $items).
  • Type Enforcing: Method add() memvalidasi bahwa hanya objek bertipe benar yang dapat masuk.
  • Logika Agregasi Terpusat: Memiliki method domain seperti hitungTotalIpk(), filterLulus(), cariByNpm().
  • Immutability: Method operasi menghasilkan instans koleksi baru tanpa merusak data asli.
Domain/Collection/MahasiswaCollection.php
namespace App\Domain\Collection; use App\Domain\Model\Mahasiswa; class MahasiswaCollection { private array $items = []; public function add(Mahasiswa $mhs): void { // ✨ Type Safety Terjamin 100% saat Compile & Runtime $this->items[] = $mhs; } public function hitungRataRataIpk(): float { if (empty($this->items)) return 0.0; $total = array_sum(array_map(fn($m) => $m->ipk, $this->items)); return $total / count($this->items); } }
🔌 STANDARD PHP LIBRARY (SPL)

Mengintegrasikan Antarmuka SPL Bawaan

Membuat objek Collection dapat dihitung dengan count() dan di-loop dengan foreach.

1. \Countable

Mengizinkan objek dipanggil langsung oleh fungsi global count().

public function count(): int { return count($this->items); }

2. \IteratorAggregate

Menyediakan generator iterator agar objek dapat di-iterasi langsung via foreach.

public function getIterator(): \Traversable { return new \ArrayIterator($this->items); }

3. \JsonSerializable

Menentukan data yang diekspor saat dipanggil oleh json_encode().

public function jsonSerialize(): array { return $this->items; }
Hasilnya: Objek $collection Anda berperilaku alami seperti array bawaan: count($koleksi), foreach($koleksi as $item), dan json_encode($koleksi) bekerja secara transparan!
🛠️ KODE IMPLEMENTASI SPL

Anatomi Lengkap First-Class Collection Modern

Menggabungkan 3 antarmuka SPL dalam satu class koleksi yang tangguh dan elegan.

Domain/Collection/MahasiswaCollection.php
<?php namespace App\Domain\Collection; use App\Domain\Model\Mahasiswa; use Countable, IteratorAggregate, JsonSerializable, ArrayIterator, Traversable; class MahasiswaCollection implements Countable, IteratorAggregate, JsonSerializable { private array $items = []; public function add(Mahasiswa $mhs): self { $this->items[] = $mhs; return $this; } public function count(): int { return count($this->items); } public function getIterator(): Traversable { return new ArrayIterator($this->items); } public function jsonSerialize(): array { return $this->items; } }
⚡ PIPELINE FUNGSIONAL

Manipulasi Array: Map, Filter, & Reduce

Meninggalkan loop imperatif yang berulang demi pipeline data fungsional yang deklaratif.

1. array_map()

Mentransformasi setiap elemen array ke bentuk baru 1-ke-1.

// Ambil seluruh nama $names = array_map( fn($m) => $m->nama, $items );

2. array_filter()

Menyaring elemen berdasarkan kriteria predikat boolean (true/false).

// Filter IPK >= 3.50 $cumlaude = array_filter( $items, fn($m) => $m->ipk >= 3.5 );

3. array_reduce()

Merangkum seluruh elemen menjadi satu nilai skalar tunggal (akumulator).

// Total SKS terdaftar $totalSks = array_reduce( $items, fn($carry, $mk) => $carry + $mk->sks, 0 );
🏹 SINTAKS MODERN

Kekuatan Arrow Functions (fn() =>)

Sintaks ringkas satu baris dengan kemampuan penangkapan variabel otomatis (*Auto-Capture by Value*).

❌ Anonymous Function Tradisional

$minIpk = 3.00; $hasil = array_filter($daftarMhs, function ($m) use ($minIpk) { return $m->ipk >= $minIpk; });

Wajib menulis klausa use ($minIpk) dan kata kunci return secara eksplisit.

✅ Modern Arrow Function

$minIpk = 3.00; // ✨ Variabel $minIpk otomatis ditangkap! $hasil = array_filter( $daftarMhs, fn($m) => $m->ipk >= $minIpk );

Sangat ringkas, bersih, dan ekspresif untuk pipeline pemrosesan data.

🆕 FITUR PHP 8.1+

Deteksi Array List dengan array_is_list()

Memastikan struktur array berupa index sekuensial numerik berurutan mulai dari 0.

📌 Kriteria Array List:

  • Kunci index berupa bilangan bulat (int).
  • Dimulai dari index 0 hingga count() - 1.
  • Tidak ada index yang bolong/hilang (*no gaps*).
  • Array kosong [] dianggap sebagai list yang valid (true).
demo_array_is_list.php
// 1. Array Sekuensial (List) array_is_list(['Apel', 'Jeruk', 'Mangga']); // true // 2. Array Asosiatif (Key String) array_is_list(['a' => 1, 'b' => 2]); // false // 3. Index Bolong / Tidak Berurutan array_is_list([0 => 'A', 2 => 'B']); // false // 4. Index Tidak Mulai dari 0 array_is_list([1 => 'A', 2 => 'B']); // false
Manfaat Praktis: Sangat penting saat serialisasi JSON API. Array list akan dirender sebagai JSON Array ["A", "B"], sedangkan array asosiatif dirender sebagai JSON Object {"0": "A", "2": "B"}.
🛡️ DEFENSIVE PROGRAMMING

Koleksi Abadi (*Immutable Collections*)

Menghindari efek samping (*Side Effects*) dengan mengembalikan instans baru pada setiap mutasi.

📌 Prinsip Immutability:

Alih-alih mengubah array internal yang sama (*in-place mutation*), method seperti filter() dan map() mengembalikan objek koleksi baru (new static(...)).

  • Menjamin keutuhan state data di bagian kode pemanggil lain.
  • Memungkinkan pemanggilan berantai (*Fluent Method Chaining*): $koleksi->filter()->sortBy().
Method Chaining pada Immutable Collection
public function filterCumlaude(): self { $filtered = array_filter( $this->items, fn($m) => $m->ipk >= 3.50 ); // ✨ Kembalikan instans baru! return new self(array_values($filtered)); }
🛒 STUDI KASUS DOMAIN

Studi Kasus: First-Class Keranjang Belanja (*Cart*)

Mengintegrasikan item produk, diskon kupon, perhitungan subtotal, dan ekspor JSON.

Domain/KeranjangBelanja.php
class KeranjangBelanja implements \Countable, \IteratorAggregate { private array $items = []; public function tambahItem(ItemBelanja $item): void { $this->items[] = $item; } public function hitungGrandTotal(float $diskon = 0.0): float { $subtotal = array_reduce( $this->items, fn($acc, $it) => $acc + $it->getSubtotal(), 0.0 ); return $subtotal * (1 - $diskon); } public function count(): int { return count($this->items); } public function getIterator(): \Traversable { return new \ArrayIterator($this->items); } }
Penggunaan di Client Controller
$cart = new KeranjangBelanja(); $cart->tambahItem(new ItemBelanja("Buku PHP 8+", 120000, 2)); $cart->tambahItem(new ItemBelanja("Kaos UUI", 85000, 1)); echo "Jumlah Item: " . count($cart); // 2 item echo "Grand Total: Rp " . $cart->hitungGrandTotal(0.10); // Iterasi langsung seperti array native: foreach ($cart as $item) { echo "- " . $item->nama . " "; }
