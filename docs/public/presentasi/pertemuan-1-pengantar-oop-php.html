🧠 Cara Berpikir

Apa itu Paradigma Pemrograman?

Sudut pandang fundamental dalam menstrukturkan solusi komputasi:

PROSEDURAL
Kumpulan Fungsi Berurutan
Data mengalir bebas antar fungsi. Cocok untuk skrip kecil, rapuh untuk sistem besar. Contoh: PHP tradisional, C.
BERORIENTASI OBJEK
Objek Mandiri Berinteraksi
Data + perilaku dibungkus dalam class. Modular & aman. Contoh: PHP 8, Java, Laravel.
FUNGSIONAL
Fungsi Murni & Imutabel
Hindari state berubah-ubah. Populer untuk data pipeline & paralel. Contoh: JS map/filter, Haskell.
⚠️ Fokus semester ini: paradigma OOP. Fungsional hanya disinggung saat memakai array_map / closure di PHP.

🔄 Evolusi • Bagian 1

Pendekatan Prosedural

Sederhana di awal, menyakitkan saat membesar:

// Prosedural: data & fungsi terpisah
function hitungLuas(float $p, float $l): float {
    return $p * $l;
}
$panjang = 10; $lebar = 5;
echo "Luas: " . hitungLuas($panjang, $lebar);
// Output: Luas: 50
✅ Kelebihan
• Mudah dipelajari pemula.
• Cepat untuk skrip sekali jalan.
• Alur top-down mudah diikuti.
❌ Kelemahan
• Data bisa diubah siapa saja.
• Nama fungsi global gampang bentrok.
• 5.000 baris = mimpi buruk maintenance.
07
🔄 Evolusi • Bagian 2

Pendekatan Berorientasi Objek

Data dan perilaku dibungkus menjadi satu kesatuan utuh:

<?php declare(strict_types=1);
class PersegiPanjang {
    public function __construct(
        private float $panjang,
        private float $lebar
    ) {}
    public function hitungLuas(): float {
        return $this->panjang * $this->lebar;
    }
}
$bangun = new PersegiPanjang(10, 5);
echo "Luas: " . $bangun->hitungLuas();
✅ Kelebihan
• Data terkunci private, akses via method tervalidasi.
• Reuse via inheritance & trait.
• Fondasi Laravel & Symfony.
• Mudah di-unit-test & diskalakan tim.
💡 Kata kunci hari ini: class = cetakan, object = hasil cetakan, $this = "saya sendiri".

🚗 Analogi Dunia Nyata

Mobil sebagai Objek

Setiap mobil punya data (merk, warna, kecepatan) dan perilaku (gas, rem):

class Mobil {
    private int $kecepatan = 0;
    public function __construct(
        private string $merk,
        private string $warna
    ) {}
    public function gas(int $a): void {
        $this->kecepatan += $a;
        echo "{merk} melaju {kecepatan} km/jam\n";
    }
    public function rem(): void {
        $this->kecepatan = 0;
    }
}
// Tiga objek, satu cetakan
$avanza = new Mobil("Toyota", "Merah");
$brio = new Mobil("Honda", "Putih");
$avanza->gas(60);  // Toyota 60 km/jam
$avanza->gas(40);  // Toyota 100 km/jam
$brio->gas(80);   // Honda 80 km/jam
🔑 State mandiri: kecepatan Avanza ≠ kecepatan Brio. Tiap objek menyimpan datanya sendiri.

🏛️ Pilar 1 / 4 • Encapsulation

🔒 Encapsulation

Bungkus data + kunci aksesnya. Dunia luar hanya lewat pintu resmi (getter/setter):

class AkunBankMini {
    public function __construct(
        public readonly string $noRek,
        private float $saldo = 0
    ) {}
    public function getSaldo(): float {
        return $this->saldo;
    }
    public function setor(float $j): void {
        if ($j <= 0)
            throw new InvalidArgumentException("Setoran > 0");
        $this->saldo += $j;
    }
}
🛡️ Visibility di PHP
• public — bebas diakses.
• protected — class + turunan.
• private — hanya class sendiri.
• readonly (8.1) — isi sekali saat construct.
✅ Aturan emas: properti selalu private dulu. Buka ke public hanya bila ada alasan kuat.
12
🏛️ Pilar 2 / 4 • Inheritance

🧬 Inheritance & Trait

Tulis sekali, wariskan ke banyak class. Trait untuk reuse horizontal khas PHP:

class Pengguna {
    public function __construct(
        protected string $nama
    ) {}
    public function sapa(): string {
        return "Halo, " . $this->nama;
    }
}
class Mahasiswa extends Pengguna {
    use NotifikasiTrait;
    public function sapa(): string {
        return parent::sapa() . " (NIM: 123)";
    }
}
🌳 Hierarki vs Horizontal
• extends — pewarisan vertikal (is-a).
• parent:: — panggil versi induk.
• trait — tempel kemampuan lintas hierarki (Loggable, Notifiable).
• PHP: single inheritance + banyak trait.
⚠️ Jebakan: jangan wariskan hanya demi reuse. Kalau bukan hubungan "adalah", pakai trait atau komposisi.
13
🏛️ Pilar 3 / 4 • Polymorphism

🎭 Polymorphism

Satu perintah, banyak perilaku. Method yang sama, objek berbeda:

function prosesBayar(MetodeBayar $m, int $nominal): string {
    return $m->bayar($nominal);
}
$tunai = new Tunai();
$qris = new Qris();
prosesBayar($tunai, 50000); // "Diterima tunai"
prosesBayar($qris, 50000);  // "QRIS terverifikasi"
🔌 Kuncinya: Type Hinting
Parameter bertipe parent/interface menerima semua turunannya. Tambah metode baru tanpa ubah fungsi lama — open/closed principle mini.
💡 Overriding = anak menulis ulang method induk dengan nama & signature sama, isi berbeda.

🏛️ Pilar 4 / 4 • Abstraction

🧩 Abstraction

Tampilkan apa-nya, sembunyikan bagaimana-nya:

interface BisaDibayar {
    public function bayar(int $nominal): string;
}
abstract class Dokumen {
    abstract public function cetak(): string;
    public function arsipkan(): void { /* ... */ }
}
Abstract ClassInterface
IsiBisa ada implementasiHanya kontrak
Warisan1 induk sajaBisa banyak
KapanKeluarga sejenisKemampuan lintas jenis
✅ Decoupling: kode bergantung pada kontrak, bukan wujud konkret. Ganti implementasi tanpa jebol sistem.

💻 Live Code

Studi Kode: "AkunBank"

Constructor promotion + readonly + validasi + named arguments:

<?php declare(strict_types=1);
class AkunBank {
    public function __construct(
        public readonly string $nomorRekening,
        public string $pemilik,
        private float $saldo = 0.0
    ) {}
    public function getSaldo(): float {
        return $this->saldo;
    }
    public function setor(float $j): void {
        if ($j <= 0)
            throw new InvalidArgumentException("Setoran harus > 0");
        $this->saldo += $j;
    }
}
// Client code — named arguments
$rek = new AkunBank(
    nomorRekening: "123-456-789",
    pemilik: "Budi Santoso",
    saldo: 500_000
);
echo $rek->pemilik . "\n";
$rek->setor(250_000);
echo "Saldo: Rp " .
  number_format($rek->getSaldo(),0,',','.');
// Saldo: Rp 750.000

🎮 Cek Pemahaman

Kuis Kilat 3 Menit

Klik pertanyaan untuk membuka jawaban — jawab dulu sebelum intip:

❓ 1. Apa beda class dan object?
✅ Class = cetakan/desain (mis. resep). Object = hasil cetakan yang hidup di memori (mis. kue). Satu class bisa melahirkan banyak object via new.
❓ 2. Kenapa properti saldo dibuat private?
✅ Agar tidak diubah sembarangan dari luar. Semua perubahan wajib lewat setor() yang memvalidasi nominal > 0 — inilah encapsulation.
❓ 3. Kapan pakai interface vs abstract class?
✅ Interface untuk kontrak kemampuan lintas jenis (BisaDibayar). Abstract untuk kerangka keluarga sejenis yang boleh membawa implementasi bersama.
