Filosofi Polymorphism

"Poly" = Banyak, "Morph" = Bentuk. Kemampuan objek berbeda merespons pesan yang sama:

🌍 Client Code
$kasir->checkout($metode)
Hanya tahu tipe MetodePembayaran

Mengapa Sangat Penting?
Client code tidak perlu pusing menulis puluhan baris switch ($tipe) atau if-else bertingkat. Cukup panggil method bayar(), dan objek itu sendiri yang tahu cara memprosesnya!
Open-Closed Principle (SOLID):
Sistem terbuka untuk penambahan fitur baru (*Open for extension*), tetapi tertutup untuk modifikasi kode yang sudah berjalan stabil (*Closed for modification*).
⚡ Runtime Behavior

Dynamic Method Dispatch

PHP menentukan method mana yang dijalankan berdasarkan class objek aktual saat runtime:

class Hewan {
    public function bersuara(): string { return "Suara umum hewan..."; }
}

class Kucing extends Hewan {
    public function bersuara(): string { return "🐱 Meong... meong!"; }
}

class Anjing extends Hewan {
    public function bersuara(): string { return "🐶 Guk... guk!"; }
}

// Fungsi menerima tipe umum Superclass (Hewan)
function cetakSuara(Hewan $h): void {
    echo $h->bersuara() . "\n";
}

cetakSuara(new Kucing()); // Output: 🐱 Meong... meong!
cetakSuara(new Anjing()); // Output: 🐶 Guk... guk!
📚 Koleksi Objek Heterogen

Array Polimorfik

Memproses sekumpulan objek dari class yang berbeda dengan satu instruksi perulangan:

// Array berisi berbagai turunan Hewan
$kebunBinatang = [
    new Kucing(),
    new Anjing(),
    new Burung(),
    new Kucing()
];

// Polimorfik Loop: Bersih dan seragam!
foreach ($kebunBinatang as $hewan) {
    echo $hewan->bersuara() . "\n";
}
Kelebihan Pendekatan Polimorfik:
1. Tanpa Percabangan: Tidak ada if ($hewan == 'kucing').

2. Fleksibilitas Skala: Jika besok Anda menambahkan 10 hewan baru (misal: Gajah, Singa), perulangan foreach di atas tidak perlu diubah sama sekali!
🛡️ Type Safety

Operator instanceof

Memeriksa apakah sebuah variabel merupakan instance dari class atau turunan tertentu:

class KlinikHewan {
    public function rawat(Hewan $h): void {
        // Aksi umum
        echo $h->bersuara() . "\n";

        // Type Checking aman dengan instanceof
        if ($h instanceof Kucing) {
            echo "💉 Vaksin khusus kucing diberikan.\n";
        } elseif ($h instanceof Anjing) {
            echo "🧼 Mandi anti-kutu anjing dilakukan.\n";
        }
    }
}
Kapan Menggunakan instanceof?
• Validasi Keamanan: Memastikan objek yang diterima mengimplementasikan class/interface yang diharapkan sebelum memanggil method khusus.

• Pattern Matching: Menjalankan logika spesifik yang hanya ada di salah satu subclass.

Studi Kasus: Payment Gateway

Hierarki Superclass MetodePembayaran dan Subclass TransferBank & QRIS:

abstract class MetodePembayaran {
    public function __construct(protected float $nominal) {}
    abstract public function prosesBayar(): string;
}

class TransferBank extends MetodePembayaran {
    public function __construct(float $nominal, private string $bank, private string $rek) {
        parent::__construct($nominal);
    }
    public function prosesBayar(): string {
        return "🏦 Transfer {$this->bank} ({$this->rek}): Rp " . number_format($this->nominal) . " [SUKSES]";
    }
}

class PembayaranQRIS extends MetodePembayaran {
    public function prosesBayar(): string {
        return "📱 Scan QRIS Merchant: Rp " . number_format($this->nominal) . " [LUNAS INSTAN]";
    }
}
🛒 Client Code Checkout

Client Kasir E-Commerce Polimorfik

Class Kasir mengeksekusi pembayaran tanpa perlu tahu jenis vendor:

class KasirOnline {
    // Type Hinting Polimorfik: Menerima SEMUA turunan!
    public function checkout(MetodePembayaran $metode): void {
        echo "Memulai Transaksi...\n";
        echo $metode->prosesBayar() . "\n\n";
    }
}

$kasir = new KasirOnline();

// Bayar via Transfer Bank
$kasir->checkout(new TransferBank(500_000, "BCA", "123-456"));

// Bayar via QRIS
$kasir->checkout(new PembayaranQRIS(35_000));
Dampak Desain Software:
• High Cohesion, Low Coupling: Class KasirOnline sama sekali tidak terikat pada vendor bank atau e-wallet tertentu.

• Mudah Diuji (Testable): Sangat mudah membuat Mock Payment untuk unit testing.
⚖️ Konsep Krusial PHP

Method Overriding vs Overloading di PHP

Catatan penting bagi mahasiswa yang sebelumnya belajar Java / C++:

Fitur Dukungan di PHP 8+ Penjelasan Mekanisme
Method Overriding ✅ Didukung Penuh Subclass menimpa method parent dengan nama & parameter kompatibel.
Method Overloading (Multiple signature) ❌ Tidak Ada secara Native PHP tidak mengizinkan 2 method bernama sama dalam 1 class.
Solusi Modern di PHP 8 ✅ Union Types & Default Value Gunakan int|float, parameter default, atau Named Arguments.
