🧠 REFLEKSI FILOSOFIS DATA

Mengapa Data Harus Memiliki Tipe?

Dari deretan tegangan listrik biner menuju makna semantik informasi

💡 Ilusi Biner Mesin

Bagi prosesor komputer, memori RAM hanyalah miliaran kapasitor mini yang berisi muatan listrik: 1 (High Voltage) atau 0 (Low Voltage).

CPU tidak tahu apakah pola bit 01000001 adalah angka 65, huruf 'A', atau instruksi Assembly! Tipe Data adalah kontrak filosofis yang memberi makna semantik dan aturan operasi pada bit-bit mati tersebut.

🏛️ Teori Informasi Claude Shannon

Claude Shannon (1948) membuktikan bahwa informasi adalah reduksi dari ketidakpastian (entropy), yang dapat diukur secara eksak dalam satuan Bit (Binary Digit).

🧠 MODEL MEMORI FISIK

Anatomi Variabel di Dalam Memori RAM

4 Dimensi Eksistensi Variabel dalam Komputasi Modern

4 Atribut Mutlak Variabel:

  1. Nama (Identifier): Simbol pemanggil manusia (misal: umur).
  2. Tipe Data: Menentukan lebar bit (1B, 4B, 8B) & aturan format.
  3. Alamat Memori (Pointer Address): Lokasi fisik bus data RAM (misal: 0x7ffee4b6a8).
  4. Nilai Biner (Value): Keadaan tegangan fisik saat ini (misal: 20).

Peta Memori RAM (Arsitektur Byte-Addressable):

[0x1000] : [ 00000000 00010100 ] -> int umur (4 Bytes)
[0x1004] : [ 01000000 01110110 ] -> float ipk (4 Bytes)
[0x1008] : [ 01000001 ] -> char grade (1 Byte)

Deklarasi, Inisialisasi & Konstanta (`const`)

Membedakan data dinamis (mutable) dengan kebenaran matematis mutlak (immutable)

Aturan Identifier yang Bersih:

  • Gunakan gaya camelCase untuk variabel (totalBayar).
  • Gunakan gaya UPPER_SNAKE_CASE untuk konstanta (PI_VALUE).
  • Dilarang diawali angka dan kata kunci cadangan (reserved keywords).

🔄 TRANSFORMASI MEMORI

Konversi Tipe Data (Type Casting)

Rekonstruksi bit biner: Melebarkan wadah vs memotong informasi

1. Widening Casting (Implisit / Otomatis)

Mengalirkan data dari wadah kecil (misal int 4B) ke wadah lebih besar (misal double 8B). Aman 100% tanpa kehilangan informasi (lossless). 

int skor = 95;
double skorDesimal = skor; // Menjadi 95.0

2. Narrowing Casting (Eksplisit / Manual)

Memaksa data dari wadah besar ke wadah kecil. Berisiko fatal pemotongan desimal (truncation) atau overflow. 

double ipk = 3.92;
int ipkBulat = (int)ipk; // Menjadi 3 (0.92 hilang!)

Studi Kasus: Presisi Perhitungan Lingkaran

Penerapan tipe floating-point ganda, manipulasi konstanta, dan pemformatan output

🐍 Python 3
# Hitung Lingkaran Presisi di Python
import math

r = float(input("Jari-jari lingkaran (r): "))
luas = math.pi * (r ** 2)
keliling = 2 * math.pi * r

print(f"Luas     : {luas:.4f}")
print(f"Keliling : {keliling:.4f}")
⚡ C++
#include <iostream>
#include <iomanip>
#include <cmath>
using namespace std;

int main() {
    const double PI = M_PI;
    double r;
    cout << "Jari-jari lingkaran (r): "; cin >> r;

    double luas = PI * pow(r, 2);
    double keliling = 2 * PI * r;

    cout << fixed << setprecision(4);
    cout << "Luas     : " << luas << "\n";
    cout << "Keliling : " << keliling << "\n";
    return 0;
}
⚠️ ANOMALI KOMPUTASI

Jebakan Klasik Memori & Representasi

Ketika batasan arsitektur fisik mesin berbenturan dengan intuisi matematika

1. Integer Division Trap

Di bahasa C/C++/Java, ekspresi 5 / 2 menghasilkan 2 (bukan 2.5) karena kedua operan integer.

Solusi: Gunakan minimal satu literal float: 5.0 / 2.

2. Integer Overflow

Menambahkan 1 pada angka integer maksimum (+2.147.483.647) akan memutar nilai menjadi negatif minimum (-2.147.483.648).

3. Floating-Point Rounding

Pecahan desimal 0.1 + 0.2 di memori biner menghasilkan 0.30000000000000004 akibat limitasi IEEE 754.
