🧠 MODEL MEMORI

Apa itu Variabel di Memori RAM?

Variabel adalah wadah bernama di RAM untuk menyimpan nilai sementara

4 Atribut Utama Variabel:

  1. Nama (Identifier): Label unik pemanggil (misal: umur).
  2. Tipe Data: Menentukan ukuran byte dan format bit.
  3. Alamat Memori: Lokasi fisik di RAM (misal: 0x7ffee4b6a8).
  4. Nilai (Value): Data biner aktual yang tersimpan (misal: 20).

Ilustrasi Alokasi RAM:

[0x1000] : [ 20 ] -> int umur (4 Bytes)
[0x1004] : [ 3.85 ] -> float ipk (4 Bytes)
[0x1008] : [ 'A' ] -> char grade (1 Byte)
📊 TAKSONOMI TIPE DATA

Klasifikasi Tipe Data Komputer

Membagi tipe data berdasarkan struktur dan sifat alokasinya

1. Tipe Data Primitif (Sederhana)

Tipe data bawaan tunggal yang langsung didukung oleh instruksi CPU hardware:

  • Integer: Bilangan bulat (int, short, long).
  • Floating-Point: Bilangan desimal/pecahan (float, double).
  • Character: Karakter tunggal ASCII (char).
  • Boolean: Logika biner (bool: true / false).

2. Tipe Data Komposit (Terstruktur)

Tipe data bentukan yang tersusun dari kombinasi tipe data lainnya:

  • Array (Larik): Kumpulan elemen homogen berurutan.
  • String: Kumpulan karakter teks sekuensial.
  • Struct / Record / Class: Kumpulan elemen heterogen.

✍️ SINTAKSIS DASAR

Deklarasi Variabel & Konstanta

Perbedaan variabel (dapat berubah) vs konstanta (nilai tetap / immutable)

Aturan Penamaan Identifier yang Baik:

  • Hanya boleh huruf, angka, dan garis bawah (_).
  • Tidak boleh diawali dengan angka (misal: 2nilai ❌).
  • Bersifat Case-Sensitive (total ≠ Total).
  • Gunakan gaya camelCase atau snake_case deskriptif.
// 1. Variabel (Dapat diubah nilainya)
int jumlahMahasiswa = 35;
jumlahMahasiswa = 40; // Valid

// 2. Konstanta (Nilai Tetap / Readonly)
const double PI = 3.1415926535;
const int SKS_MAX = 24;

// PI = 3.14; // ERROR: assignment of read-only variable!
🔄 KONVERSI TIPE

Konversi Tipe Data (Type Casting)

Mengubah representasi data dari satu tipe ke tipe data lainnya

1. Konversi Implisit (Widening / Auto)

Terjadi otomatis oleh kompilator saat tipe data kecil dimasukkan ke tipe data lebih besar. Aman dari kehilangan data (*no data loss*). 

int a = 10;
double b = a; // Otomatis menjadi 10.0

2. Konversi Eksplisit (Narrowing / Casting)

Dijalankan secara manual oleh programmer saat mengubah tipe besar ke kecil. Berisiko pemotongan desimal (*truncation*). 

double nilaiUjian = 87.85;
int nilaiBulat = (int)nilaiUjian; // Menjadi 87

Studi Kasus: Perhitungan Luas & Keliling Lingkaran

Menerapkan konstanta, tipe double, dan manipulasi formula matematika

🐍 Python 3

⚡ C++
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    const double PI = 3.1415926535;
    double r, luas, keliling;
    
    cout << "Jari-jari (r): "; cin >> r;
    luas = PI * r * r;
    keliling = 2 * PI * r;

    cout << fixed << setprecision(2);
    cout << "Luas     : " << luas << "\n";
    cout << "Keliling : " << keliling << "\n";
    return 0;
}
⚠️ JEBAKAN UMUM

Jebakan Umum Pemula (Common Pitfalls)

Kesalahan logika yang sering memicu bug pada pemrograman awal

1. Pembagian Integer

Dalam C++/Java, 5 / 2 menghasilkan 2 (bukan 2.5) karena kedua operan bertipe integer.

Solusi: Gunakan desimal 5.0 / 2.

2. Integer Overflow

Memasukkan nilai lebih besar dari kapasitas tipe data (misal > 2.14 miliar pada int 32-bit) akan memutar nilai menjadi negatif.

3. Variabel Tanpa Inisialisasi

Membaca variabel yang belum diberi nilai awal di C++ akan menghasilkan garbage value (nilai sampah memori acak).
