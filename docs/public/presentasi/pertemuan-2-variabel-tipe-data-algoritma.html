🔍 Abstraksi Alamat

Variabel = Nama untuk Alamat RAM

Empat atribut yang melekat pada setiap variabel yang kamu deklarasikan:

umurMahasiswa // identifier
0x7ffee4b6a8 // alamat fisik RAM
00010101₂ = 21 // pola bit (int 4 byte)
💡 Menulis int umur = 21; = meminjam 4 byte di alamat itu, lalu mengecapnya "umur".
🧬 4 atribut variabel
• Identifier — label manusia: umurMahasiswa
• Data type — jatah byte + cara baca bit
• Address — indeks heksa unik: 0x7ffee4b6a8
• Value — pola bit aktual di sel itu

🗄️ Virtual Memory Address Space

Lima Penghuni RAM

Dari yang paling dinamis hingga yang read-only:

🥞
1. Stack ↓
Variabel lokal + parameter + call frame. Cepat & otomatis. Tumbuh ke bawah.
📦
2. Heap ↑
Alokasi dinamis runtime (new, malloc). Manual / garbage collector. Tumbuh ke atas.
📑
3. BSS
Global & statis belum diinisialisasi — otomatis diisi 0.
💾
4. Data
Global & statis sudah punya nilai awal eksplisit.
⚙️
5. Text / Code
Instruksi biner mesin, read-only, dieksekusi CPU langsung.
🧪
Di mana umur?
int umur = 21; di dalam main → Stack. Global di luar fungsi → Data/BSS.

⚖️ Duel Segmen

Stack vs Heap

Dua segmen yang paling sering ditanya di kuis & interview:

Dimensi🥞 Stack📦 Heap
IsiLokal, parameter, call frameObjek dinamis, array besar
KecepatanSangat cepat (pointer geser)Lebih lambat (cari blok bebas)
Umur dataOtomatis hilang saat fungsi returnHidup hingga di-free / GC

⚠️ Jembatan ke P11 (Rekursi): tiap panggilan rekursif menumpuk 1 frame di stack. Tanpa base case → stack meledak.

🗂️ Klasifikasi

Primitif vs Komposit

Peta keluarga tipe data sebelum masuk ke tabel spesifikasi:

PRIMITIF (ATOMIC)
Disediakan CPU/kompilator
🔢 Integral: bool, char, short, int, long long
🌊 Floating: float (32-bit), double (64-bit)
KOMPOSIT / TURUNAN
Disusun dari primitif
Array, struct, pointer, string, class.
Bertemu lagi di P6 (Array) & PBO.
💡 Prinsip: tipe = kontrak ganda: berapa byte dipinjam + bagaimana bit dibaca. Pola 01000001 bisa berarti 65 (int) atau 'A' (char)!

📏 Spesifikasi C++ 64-bit • 2

Bilangan Riil (IEEE 754)

Pecahan disimpan sebagai 3 komponen: tanda, eksponen, mantissa:

TipeUkuranFormat BitPresisi
float4 Bytes1 sign + 8 exp + 23 mantissa~7 digit desimal
double8 Bytes1 sign + 11 exp + 52 mantissa~15–17 digit desimal
🎯 Aturan praktis
Uang, IPK, sains → selalu double. float hanya untuk data masif (grafis jutaan titik).
⚠️ Harga presisi
0.1 desimal = biner berulang tak hingga (0.000110011…). Slide 12 membuktikan akibatnya.

💥 Integer Overflow

2147483647 + 1 = −2147483648?!

Bit tanda terbalik → nilai melompat ke ekstrem berlawanan (wrap-around):

int maxInt = 2147483647; // INT_MAX
std::cout << maxInt + 1;
// Output: -2147483648 😱
INT_MAX     : 2147483647
+1 (OVERFLOW): -2147483648
🚀 Ariane 5 (1996): konversi float 64-bit ke integer 16-bit yang overflow meledakkan roket $370 juta dalam 37 detik. Bug tipe data termahal sepanjang sejarah.
✅ Obatnya: data finansial/NIM besar → long long / int64_t. Python aman otomatis (bignum, slide 18).
13
🌊 IEEE 754 Imprecision

0.1 + 0.2 ≠ 0.3

Pecahan desimal tak eksak dalam biner — jangan pernah bandingkan float dengan ==:

// ❌ SALAH — bisa FALSE!
if (0.1 + 0.2 == 0.3) { ... }

// ✅ BENAR — toleransi epsilon
if (abs((0.1+0.2)-0.3) < 1e-9) { ... }
0.1 + 0.2 = 0.30000000000000004
0.1 × 10 (akumulator) = 0.9999999999999999
⚠️ Tugas misi 2: jumlahkan 0.1 sepuluh kali, cetak, dan jelaskan kenapa bukan tepat 1.0. Petunjuk: 0.1 = 0.000110011…₂ berulang.

BAGIAN IV — TYPING & CASTING

🔒 Siapa Menjaga Tipemu?

Kompilator yang galak vs interpreter yang santai — plus jebakan klasik 275/3.

15
⚙️ Sistem Pengetikan

Static vs Dynamic Typing

Kapan tipe diperiksa menentukan kecepatan, keamanan, dan gaya coding:

STATIC — C++, JAVA, RUST
• Dicek saat kompilasi.
• Variabel tak bisa ganti tipe.
• Cepat + minim bug runtime.
• int x = 5; x = "a"; // ERROR
DYNAMIC — PYTHON, JS
Tipe menempel pada nilai
• Dicek saat eksekusi.
• Variabel bebas ganti tipe.
• Fleksibel, tuntut disiplin.
• x = 5; x = "a" # sah!
💡 Mnemonic: static = "KTP dikunci sejak lahir", dynamic = "profesi boleh ganti kapan saja, yang penting orangnya sama".
16
🔄 Konversi Tipe

Casting & Jebakan 275/3

Kasus paling sering bikin nilai IPK salah hitung di tugas mahasiswa:

int total = 275, n = 3;
// ❌ Desimal terpotong: 91.0
double salah = total / n;
// ✅ Cast dulu: 91.6667
double benar = static_cast<double>(total) / n;
Dua metode casting
• Implisit (promotion): otomatis kecil → besar, int + double → double.
• Eksplisit: sadar & manual — C++ static_cast<int>(x), Python int(x).
⚠️ Python beda jebakan: / selalu float, // floor. 275/3 = 91.66, 275//3 = 91.

💻 C++ • Inspeksi RAM

sizeof & Alamat Fisik

Lihat sendiri byte dan alamat tiap variabel di RAM-mu:

int umur = 21;
double ipk = 3.85;
char grade = 'A';
std::cout << sizeof(umur)      // 4
  << sizeof(ipk)       // 8
  << sizeof(grade);    // 1
std::cout << &umur;  // 0x7ffee4b6a8
umur  : 21 | 4 Byte | 0x7ffee4b6a8
ipk   : 3.85 | 8 Byte | 0x7ffee4b6a0
grade : A | 1 Byte | 0x7ffee4b69f
✅ Misi lab: jalankan, bandingkan alamat berurutan (stack tumbuh ke bawah!), lalu coba sizeof(long long).
19
🐍 Python • Fleksibel Tapi Mahal

Bignum & Overhead Objek

Python tak kenal overflow — tapi tiap angka membawa "koper" objek:

raksasa = 2**63 - 1
print(raksasa + 1)
# 9223372036854775808 ✅
# (C++ int64 sudah meledak!)

print(sys.getsizeof(21))   # 28 Bytes!
print(hex(id(umur)))       # ID memori
⚖️ Harga fleksibilitas
int C++ = 4 byte murni. int Python = 28 byte (header + refcount + tipe + nilai). Itulah kenapa numerik berat memakai NumPy.
💡 Analoginya: C++ seperti amplop pasmembrane; Python seperti paket dengan label, asuransi, dan resi — aman tapi bulky.

🎮 Cek Pemahaman

Kuis Kilat 3 Menit

Jawab dulu dalam hati, baru klik untuk membuka jawaban:

❓ 1. Variabel lokal fungsi main tinggal di segmen apa? Bagaimana dengan global terinisialisasi?
✅ Lokal → Stack (otomatis, cepat). Global terinisialisasi → Data segment; yang belum diinisialisasi → BSS (di-nol-kan otomatis).
❓ 2. int m = 2147483647; m + 1 menghasilkan?
✅ −2147483648. Overflow 32-bit: bit tanda terbalik, nilai wrap-around ke minimum. Obat: long long.
❓ 3. Kenapa total/nilai (275/3, keduanya int) memberi 91.0 di C++?
✅ Integer division truncation. Perlu static_cast<double>(total)/n → 91.6667. Di Python, / selalu float — jebakannya justru //.
