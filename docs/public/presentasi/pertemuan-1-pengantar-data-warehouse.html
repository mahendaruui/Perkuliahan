🏛️ Definisi

Empat Karakteristik Data Warehouse

Definisi Inmon yang masih menjadi rujukan:

🎯 Subject-Oriented
Diorganisasi berdasarkan subjek bisnis (penjualan, pelanggan), bukan aplikasi sumber.
🔗 Integrated
Menyatukan banyak sumber dengan definisi, kode, dan format yang konsisten.
🕰️ Time-Variant
Menyimpan histori dan konteks waktu, bukan hanya kondisi terkini.
🔒 Nonvolatile
Data dimuat dan dibaca; perubahan terkontrol, tidak update sembarangan.
💡 Business Intelligence adalah payung proses & teknologi untuk mengubah data menjadi keputusan; DW adalah fondasinya.

🔬 Analisis

Melihat Perbedaan Beban Secara Nyata

Jalankan dua query dan bandingkan:

-- OLTP: satu baris
EXPLAIN ANALYZE
SELECT * FROM oltp.orders
WHERE order_id = 12345;

-- OLAP: agregasi seluruh data
EXPLAIN ANALYZE
SELECT date_trunc('month', order_ts) AS bulan,
       category,
       SUM(quantity * unit_price) AS revenue
FROM oltp.orders
WHERE status = 'paid'
GROUP BY 1, 2
ORDER BY 1, 3 DESC;
💡 Yang Diamati
Query OLAP memindai hampir seluruh tabel. Jika dijalankan berulang di database operasional, aplikasi kasir melambat.
⚠️ Inilah alasan teknis dan bisnis mengapa analitik dipisahkan ke data warehouse.

🎮 Refleksi

Kuis Kilat 3 Menit

Jawab dulu, lalu klik untuk membuka jawaban:

❓ Mengapa data warehouse disebut nonvolatile?
✅ Data dimuat dan dibaca; transaksi historis tidak di-update sembarangan. Koreksi dilakukan melalui proses ETL terkontrol agar histori tetap dapat diaudit.
❓ Apa perbedaan data mart dan data warehouse?
✅ Data mart fokus pada satu domain/departemen dan lebih kecil; data warehouse mencakup enterprise dan menjadi sumber konsistensi lintas domain.
❓ Kapan data lake lebih tepat daripada data warehouse?
✅ Saat data mentah/beragam (gambar, log, JSON) perlu dieksplorasi oleh data scientist dan skema belum pasti. Untuk BI terstruktur, DW tetap lebih tepat.
