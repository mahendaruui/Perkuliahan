📐 FONDASI MATEMATIKA

Konsep Operator, Operand & Ekspresi

Anatomi pembentukan instruksi komputasi dalam kode program

1. Operator

Simbol khusus yang menginstruksikan CPU untuk melakukan operasi matematis atau logika (misal: +, *, ==).

2. Operand

Nilai atau variabel yang menjadi target manipulasi oleh operator (misal: x, 10, y).

3. Ekspresi

Kombinasi terstruktur antara operator dan operand yang menghasilkan nilai tunggal: z = (x + y) * 2.

Berdasarkan Jumlah Operand:

• Unary: 1 operand (-x, !aktif, ++i)  |  • Binary: 2 operand (a + b, x > y)  |  • Ternary: 3 operand (kondisi ? true : false)

➕ ARITMATIKA & ASSIGNMENT

Operator Aritmatika & Penugasan

Operasi kalkulasi numerik dan pengisian nilai ke memori

Operator Makna Contoh (a=10, b=3)
+, -Tambah, Kurang10 + 3 = 13
*, /Kali, Bagi10 / 3 = 3 (int)
%Modulus (Sisa Bagi)10 % 3 = 1
++, --Increment, Decrementa++ -> a = 11

Compound Assignment (Singkatan Penugasan):

x += 5; ekuivalen dengan x = x + 5;

x *= 2; ekuivalen dengan x = x * 2;

x %= 3; ekuivalen dengan x = x % 3;

⚠️ Catatan: Operator Modulus (%) hanya berlaku untuk bilangan bulat (integer).

⚖️ PERBANDINGAN

Operator Relasional (Perbandingan)

Membandingkan dua nilai dan selalu menghasilkan boolean (true atau false)

Operator Keterangan Contoh (x = 7)
==Sama denganx == 7 -> true
!=Tidak sama denganx != 5 -> true
>Lebih besar darix > 10 -> false
<Lebih kecil darix < 10 -> true
>=Lebih besar sama denganx >= 7 -> true
<=Lebih kecil sama denganx <= 6 -> false

⚠️ Jebakan Fatal: = vs ==

• a = 5 adalah Assignment (memasukkan nilai 5 ke dalam variabel a).
• a == 5 adalah Comparison (menguji apakah isi a sama dengan 5).

🧠 LOGIKA BOOLEAN

Operator Logika & Short-Circuit Evaluation

Menggabungkan beberapa kondisi relasional menjadi keputusan tunggal

1. AND (&&)

Bernilai true HANYA JIKA semua kondisi bernilai true.

2. OR (||)

Bernilai true JIKA salah satu kondisi bernilai true.

3. NOT (!)

Membalikkan nilai logika: !true -> false, !false -> true.

⚡ Short-Circuit Evaluation:

Kompilator menghentikan evaluasi jika hasil akhir sudah pasti:

  • false && expr2 -> expr2 tidak akan dieksekusi karena hasil pasti false.
  • true || expr2 -> expr2 tidak akan dieksekusi karena hasil pasti true.
// Mencegah crash pembagian nol:
if (pembagi != 0 && total / pembagi > 5) {
    // Aman dieksekusi!
}
0️⃣1️⃣ MANIPULASI BIT

Operator Bitwise (Manipulasi Biner CPU)

Bekerja langsung pada level representasi bit biner di memori

Simbol Operasi Bitwise Contoh (A=5, B=3)
&Bitwise AND5 & 3 -> 0101 & 0011 = 0001 (1)
|Bitwise OR5 | 3 -> 0101 | 0011 = 0111 (7)
^Bitwise XOR5 ^ 3 -> 0101 ^ 0011 = 0110 (6)
~Bitwise NOT~5 -> Pembalikan bit 1s complement
<<Left Shift (×2ⁿ)5 << 1 -> 10 (Geser kiri 1 bit)
>>Right Shift (÷2ⁿ)5 >> 1 -> 2 (Geser kanan 1 bit)

🚀 Pemanfaatan di Industri:

  • Bitmasking: Menyimpan hak akses (*permission flags*).
  • Optimasi Kecepatan: Penggandaan / pembagian daya dua super cepat di embedded system.
  • Kriptografi & Kompresi: Manipulasi byte paket data jaringan.
🔝 HIRARKI PRIORITAS

Operator Precedence & Associativity

Urutan kasta evaluasi ekspresi oleh kompilator

Tingkat Operator Arah Asosiasi
1 (Tertinggi)(), [], .Kiri ke Kanan
2Unary: !, ++, --, -Kanan ke Kiri
3Multiplikatif: *, /, %Kiri ke Kanan
4Aditif: +, -Kiri ke Kanan
5Relasional: <, >, <=, >=Kiri ke Kanan
6Kesetaraan: ==, !=Kiri ke Kanan
7Logika AND: &&Kiri ke Kanan
8Logika OR: ||Kiri ke Kanan
9 (Terendah)Assignment: =, +=, dllKanan ke Kiri

Contoh Evaluasi:

int hasil = 5 + 3 * 2;
// 3 * 2 dihitung dulu (6)
// 5 + 6 = 11 (Bukan 16!)

int hasil2 = (5 + 3) * 2;
// Tanda kurung memenangkan prioritas
// 8 * 2 = 16
💻 STUDI KASUS PRAKTIKUM

Studi Kasus: Sistem Uji Tahun Kabisat

Menerapkan gabungan operator modulus, relasional, dan logika boolean

🐍 Python 3
# Uji Kabisat di Python
tahun = int(input("Tahun: "))

# Logika: Habis dibagi 400 ATAU (Habis dibagi 4 TAPI TIDAK habis dibagi 100)
is_kabisat = (tahun % 400 == 0) or (tahun % 4 == 0 and tahun % 100 != 0)

if is_kabisat:
    print(f"Tahun {tahun} adalah KABISAT")
else:
    print(f"Tahun {tahun} BUKAN Kabisat")
⚡ C++
#include <iostream>
using namespace std;

int main() {
    int tahun;
    cout << "Tahun: "; cin >> tahun;

    bool isKabisat = (tahun % 400 == 0) || (tahun % 4 == 0 && tahun % 100 != 0);

    if (isKabisat) {
        cout << tahun << " adalah KABISAT\n";
    } else {
        cout << tahun << " BUKAN Kabisat\n";
    }
    return 0;
}
