📝 Sintaks PHP 8+

Anatomi Deklarasi Class

Menulis class bersih dengan declare(strict_types=1); dan tipe data eksplisit:

<?php
declare(strict_types=1);

class Mahasiswa
{
    // 1. Properti Bertipe (Typed Properties)
    public string $nim;
    public string $nama;
    public string $jurusan = "Sistem Informasi"; // Nilai default
    public float $ipk = 0.0;

    // 2. Method / Perilaku Objek
    public function belajar(string $mataKuliah): void
    {
        echo "{$this->nama} sedang belajar {$mataKuliah}.\n";
    }
}
🎯 Operator Arrow (->)

Instansiasi & Mengakses Member Objek

Gunakan operator new untuk membuat objek dan -> untuk mengakses properti/method:

// 1. Instansiasi Objek 1
$mhs1 = new Mahasiswa();
$mhs1->nim = "240101001";
$mhs1->nama = "Ahmad Pratama";
$mhs1->ipk = 3.85;

// 2. Instansiasi Objek 2
$mhs2 = new Mahasiswa();
$mhs2->nim = "240101002";
$mhs2->nama = "Rina Melati";
$mhs2->jurusan = "Informatika";
$mhs2->ipk = 3.92;

// 3. Panggil Method
$mhs1->belajar("PHP OOP");
$mhs2->belajar("Basis Data");
Output Eksekusi:
Ahmad Pratama sedang belajar PHP OOP.
Rina Melati sedang belajar Basis Data.
💡 Aturan Penting PHP:
Saat mengakses properti lewat tanda panah, jangan sertakan tanda $ pada nama properti!
• Benar: $mhs1->nama
• Salah: $mhs1->$nama
🔍 Scope & Context

Memahami Variabel Pseudo $this

$this selalu merujuk pada objek yang sedang aktif mengeksekusi method tersebut:

class PersegiPanjang {
    public float $panjang;
    public float $lebar;

    public function hitungLuas(): float {
        // $this merujuk ke properti objek pemanggil
        return $this->panjang * $this->lebar;
    }
}

$buku = new PersegiPanjang();
$buku->panjang = 20.0;
$buku->lebar = 10.0;
echo $buku->hitungLuas(); // 200
Tanpa $this?
Jika Anda hanya menulis $panjang di dalam method, PHP akan menganggapnya sebagai variabel lokal di method, bukan properti milik objek!
Kapan $this Tidak Tersedia?
Variabel $this tidak ada di dalam static method karena static method dipanggil di level Class, bukan level instance objek.
⚠️ Error Prevention

Jebakan: Uninitialized Typed Property

Fitur keamanan tipe data PHP 7.4+ yang wajib diwaspadai:

❌ KODE BERBAHAYA 
class User {
    public string $username; // Tanpa default
}

$u = new User();
// Membaca sebelum diisi:
echo $u->username; 

// 💥 FATAL ERROR: 
// Typed property User::$username must not 
// be accessed before initialization
✅ SOLUSI REKOMENDASI

1. Berikan Nilai Default:
public string $username = "";

2. Gunakan Nullable Type:
public ?string $username = null;

3. Inisialisasi via Constructor (Pertemuan 3):
public function __construct(string $username) ...

🧠 Zend Engine Memory

Manajemen Memori: Referensi vs Clone

Objek di PHP dilewatkan berdasarkan *Object Handle*, bukan duplikasi nilai mentah:

// Kasus 1: Assignment Referensi (Menunjuk Objek yang SAMA)
$a = new Mahasiswa();
$a->nama = "Budi";

$b = $a;         // $b dan $a menunjuk ke alamat memori yang sama!
$b->nama = "Siti";
echo $a->nama;   // Output: "Siti" (Nilai $a ikut berubah!)

// Kasus 2: Duplikasi Objek Fisik Menggunakan Keyword clone
$c = clone $a;   // Membuat salinan objek baru yang independen
$c->nama = "Andi";
echo $a->nama;   // Output tetap: "Siti"
🛒 Praktikum Terbimbing

Studi Kasus: Class Produk Kasir

Mengintegrasikan properti, validasi, method ber-parameter, dan return boolean:

class Produk {
    public string $kode;
    public string $nama;
    public float $harga;
    public int $stok = 0;

    public function jual(int $qty): bool {
        if ($this->stok >= $qty) {
            $this->stok -= $qty;
            return true;
        }
        return false;
    }
}
Fitur Class Produk:
• Menyimpan data katalog (kode, nama, harga, stok).
• Method jual($qty) memvalidasi kecukupan stok sebelum mengurangi stok.
• Mengembalikan status boolean true / false ke kasir.
• Menghitung subtotal transaksi belanja secara real-time.
