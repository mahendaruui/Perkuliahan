📐 Konsep Fundamental

Class vs Object

Satu cetak biru melahirkan banyak wujud hidup di memori (Zend Engine):

CETAK BIRU / CLASS
Mahasiswa
Properti: $nim $nama $ipk
Method: belajar() cetakInfo()
⬇ new Mahasiswa() × 3 ⬇
HANDLE #1
Ahmad

HANDLE #2

HANDLE #3

📐 Class = Struktur Abstrak
Tipe data bentukan pengembang. Mendefinisikan atribut (properti) dan perilaku (method). Belum makan memori data.
🧍 Object = Wujud Konkret
Instance yang dialokasikan di memori dengan state spesifik. Tiap objek punya salinan datanya sendiri.
💡 Analogi: class = resep kue, object = kue yang sudah dipanggang. Satu resep → banyak kue berbeda rasa.
03
🔬 Bedah Sintaks

Anatomi Class Mahasiswa

Dua penghuni class: properti (data) dan method (perilaku) — dengan strict typing:

<?php declare(strict_types=1);
class Mahasiswa
{
    // 1. Typed Properties (PHP 7.4+)
    public string $nim;
    public string $nama;
    public string $jurusan = "Sistem Informasi";
    public float $ipk = 0.0;

    // 2. Method (perilaku)
    public function belajar(string $mk): void
    {
        echo "{nama} belajar {mk}\n";
    }
}
🧩 Tiga bagian deklarasi
• class Nama — nama PascalCase.
• visibility type $prop — properti bertipe.
• function nama(): return — method bertipe.
⚠️ Perhatikan: $nim & $nama tanpa nilai default — wajib diisi sebelum dibaca, atau fatal error (slide 12)!
✅ Standar kelas: selalu awali file dengan declare(strict_types=1) agar PHP menolak tipe yang salah.

05
⚙️ Perilaku Objek

Method: Nyawa Objek

Properti menyimpan keadaan, method melakukan aksi — dan selalu lewat $this:

public function belajar(string $mataKuliah): void
{
    echo $this->nama . " belajar " . $mataKuliah;
}

public function cetakInfo(): void
{
    echo "NIM  : " . $this->nim . "\n";
    echo "IPK  : " . number_format($this->ipk, 2);
}
📝 Resep menulis method
• Nama camelCase kata kerja: hitungLuas().
• Parameter bertipe + return type jelas.
• void = tidak mengembalikan nilai.
• Akses data sendiri via $this->properti.
💡 Prinsip: method adalah satu-satunya pintu resmi menuju data objek. Logika & validasi tinggal di sini, bukan tercecer di luar.

Instansiasi dengan new

Dua objek, satu class — masing-masing dengan state-nya sendiri:

$mhs1->ipk = 3.85;

08
🪞 Variabel Pseudo $this

Si Kembar $this

Di dalam method, $this otomatis merujuk ke objek yang sedang memanggil — tanpa perlu parameter:

class PersegiPanjang
{
    public float $panjang;
    public float $lebar;

    public function hitungLuas(): float
    {
        // milik SIAPA? milik pemanggil!
        return $this->panjang * $this->lebar;
    }
    public function hitungKeliling(): float
    {
        return 2 * ($this->panjang + $this->lebar);
    }
}
$pp = new PersegiPanjang();
$pp->panjang = 10.0;
$pp->lebar = 5.0;

echo $pp->hitungLuas();      // 50
echo $pp->hitungKeliling();  // 30
💡 Saat $pp->hitungLuas() dipanggil, $this di dalam method = $pp. Ganti objek, ganti pula isi $this.

11
🚨 Error Wajib Hafal

Uninitialized Typed Property

Properti bertipe tanpa default yang dibaca sebelum diisi = fatal Error:

$mhs = new Mahasiswa();
echo $mhs->nama;
// ❌ Error: Typed property
// Mahasiswa::$nama must not be
// accessed before initialization
⛔ Bukan warning biasa — eksekusi berhenti total. Error ini muncul di UTS setiap tahun!
// ✅ Solusi 1: isi dulu, baca kemudian
$mhs->nama = "Budi";
echo $mhs->nama;  // Budi

// ✅ Solusi 2: default di class
public string $nama = "-";

// ✅ Solusi 3: nullable
public ?string $wali = null;
12
🛡️ Pola Aman

Checklist Inisialisasi Aman

Empat pola agar tidak pernah kena error uninitialized lagi:

1️⃣ Default Value
Untuk data yang punya nilai wajar awal: $ipk = 0.0, $stok = 0, $jurusan = "SI".
2️⃣ Nullable + null
Untuk data yang memang boleh kosong: public ?string $wali = null; lalu cek dengan ?->.
3️⃣ Isi Seusai new
Pola modul hari ini: new → isi properti → baru panggil method. Jangan dibalik!
4️⃣ Constructor (P3)
Pekan depan: wajibkan pengisian lewat __construct + promotion. Error ini punah dengan sendirinya.
13
🧠 Zend Engine Memory

Handle, Bukan Fotokopi

Variabel objek menyimpan identifier/handle — assignment menyalin handle, bukan bendanya:

$a = new Mahasiswa();
$a->nama = "Budi";

// $b = handle yang SAMA, bukan duplikat!
$b = $a;
$b->nama = "Siti";

echo $a->nama;  // "Siti" 😱
🗺️ Peta Memori
$a ──╲
       ╲➜ 📦 Objek #1 (nama: Siti)
$b ──╱
⚠️ Dua remote, satu TV. $a dan $b mengendalikan objek yang sama. Ubah lewat satu, terlihat di keduanya.
14
🧬 Duplikat Fisik

Clone: Fotokopi Beneran

Butuh objek kembar yang independen? Pakai clone:

$c = clone $a;  // duplikat fisik!
$c->nama = "Andi";

echo $a->nama;  // tetap "Siti" ✅
echo $c->nama;  // "Andi" ✅
$b = $a$c = clone $a
Objek di memori1 (berbagi)2 (terpisah)
Ubah $b/$c$a ikut berubah$a tidak terpengaruh
Pakai kapanAlias sementaraDuplikat mandiri
💡 Ujian logika favorit: "berapa objek tercipta?" Hitung new + clone, bukan jumlah variabel!
15
📁 Disiplin File

Satu Class, Satu File

Aturan main PSR agar proyek tidak jadi sarang require berantakan:

// 📄 Mahasiswa.php — hanya class
<?php declare(strict_types=1);
class Mahasiswa { /* ... */ }

// 📄 main.php — hanya pemakaian
require_once 'Mahasiswa.php';
$mhs1 = new Mahasiswa();
$mhs1->nama = "Ahmad";
  • ✅ Nama file = nama class: Mahasiswa.php ↔ class Mahasiswa
  • ✅ Class di file sendiri, eksekusi di main.php / index.php
  • ✅ Class diawali huruf besar (PascalCase), method camelCase
  • ✅ Nanti (P9): require_once diganti autoload Composer PSR-4

💻 Live Code • Bagian 1

Kerangka Class Produk

Empat properti + tiga perilaku — perhatikan validasi di tiap method:

<?php declare(strict_types=1);
class Produk
{
    public string $kode;
    public string $nama;
    public float $harga;
    public int $stok = 0;

    public function tambahStok(int $j): void
    {
        if ($j > 0) {
            $this->stok += $j;
            echo "Stok ditambah.\n";
        } else {
            echo "Jumlah harus > 0!\n";
        }
    }
}
🔎 Bedah desain
• $kode/$nama/$harga tanpa default → wajib diisi (pelajaran slide 12!).
• $stok = 0 aman dibaca kapan saja.
• tambahStok() menolak angka ≤ 0 — data tidak pernah invalid.
✅ Pola validasi: tolak input jahat di pintu method, jangan biarkan properti diisi langsung tanpa cek.
18
💻 Live Code • Bagian 2

Method jual() + Uji Program

Logika bisnis sesungguhnya: cek validitas, cek stok, hitung subtotal:

public function jual(int $j): bool
{
    if ($j <= 0) { echo "Tidak valid!\n"; return false; }
    if ($this->stok >= $j) {
        $this->stok -= $j;
        echo "Terjual! Total: Rp " .
          number_format($this->harga * $j, 0, ',', '.');
        return true;
    }
    echo "Stok tidak cukup!\n";
    return false;
}
// Uji: stok awal 10
$p1 = new Produk();
$p1->kode = "PRD-001";
$p1->nama = "Kopi Robusta 250g";
$p1->harga = 45000;
$p1->stok = 10;
$p1->jual(3);   // ✅ sisa 7
$p1->jual(10);  // ❌ sisa 7, gagal
$p1->tambahStok(5); // sisa 12

🎮 Cek Pemahaman

Kuis Kilat 3 Menit

Jawab dulu dalam hati, baru klik untuk membuka jawaban:

❓ 1. $b = $a; lalu $b->nama = "Siti"; — berapa nilai $a->nama?
✅ "Siti". Assignment objek menyalin handle, bukan bendanya. $a dan $b menunjuk objek yang sama di memori.
❓ 2. Apa arti error "must not be accessed before initialization"?
✅ Properti bertipe dibaca sebelum pernah diisi. Solusi: isi dulu, beri default, buat nullable, atau (P3) wajibkan via constructor.
❓ 3. Di dalam method, apa isi $this?
✅ Referensi ke objek yang sedang memanggil method tersebut. Beda pemanggil → beda isi $this → beda hasil.

👥 Latihan Berpasangan

Tantangan 7 Menit

Dengan teman sebangku, trace program ini di kertas — tanpa laptop:

$x = new Produk();
$x->nama = "Teh"; $x->harga = 10000; $x->stok = 5;
$y = $x;
$y->jual(2);
$z = clone $x;
$z->jual(2);
echo $x->stok; // ???
echo $z->stok; // ???
🔓 Buka jawaban setelah diskusi
✅ $x->stok = 3, $z->stok = 1. Alur: stok 5 → $y (handle sama) jual 2 → 3 → $z clone dari 3 → jual 2 → 1. $x tidak terpengaruh clone.
⏱️ Aturan main: 5 menit trace + 2 menit pembahasan kelas. Yang benar duluan dapat poin partisipasi!
