BAGIAN I — ARSITEKTUR PLOTLY

🚀 Express vs Graph Objects

Plotly merender berbasis teknologi web standar: D3.js dan WebGL.

⚖️ Dua API

Plotly Express vs Graph Objects

Cepat dengan px, presisi dengan go:

🚀 PLOTLY EXPRESS (px)
High-level API, ringkas satu baris kode, otomatis terintegrasi Pandas Tidy DataFrame.

Ideal untuk: eksplorasi analitis cepat & chart standar.
fig = px.scatter(df, x="a", y="b",
                 color="kategori")
⚙️ GRAPH OBJECTS (go)
Low-level API, kendali presisi atas hierarki JSON, traces, dan layout.

Wajib untuk: multi-subplot kustom, dual Y-axis, kontrol UI internal.
fig = go.Figure()
fig.add_trace(go.Scatter(x=x, y=y))
💡 Aturan praktis: mulai dengan px untuk eksplorasi, lalu naik ke go saat butuh kontrol penuh.
🧬 Model Internal

Grafik = Pohon JSON

Setiap objek Plotly pada dasarnya adalah spesifikasi kamus JSON:

{
  "data": [
    {
      "type": "scatter",
      "mode": "lines+markers",
      "x": [1, 2, 3],
      "y": [4, 5, 6],
      "hovertemplate": "..."
    }
  ],
  "layout": {
    "title": "...",
    "updatemenus": [ ... ]
  }
}
🖥️ Render di Browser
Spec JSON ini dikirim ke browser dan dirender oleh D3.js (vektor) atau WebGL (jutaan titik). Karena itu grafik Plotly native interaktif — zoom, pan, dan hover tanpa backend.
✅ Konsekuensi praktis: memahami struktur JSON = memahami cara mengontrol Plotly sampai level terdalam.

🖱️ Interaksi Bawaan

Gratis dari Plotly

Tanpa satu baris kode tambahan, pengguna sudah bisa menjelajahi data:

🔍
Zoom
Perbesar area tertentu dengan scroll atau drag.
✋
Pan
Geser kanvas untuk menelusuri data di luar viewport.
💬
Hover
Lihat nilai persis tiap titik tanpa menebak.
🖽
Box Select
Pilih sekumpulan titik lalu telusuri atributnya.
✅ Solusi overplotting: data ribuan baris yang saling menumpuk di grafik statis menjadi bisa dijelajahi — tanpa perlu membuang data (ingat: integritas data P3).
💬 Hover Kustom

hovertemplate

Ganti tooltip bawaan dengan format profesional (mata uang, tanggal, HTML):

go.Scatter(
    x=df["Tanggal"], y=df["Harga"],
    hovertemplate=(
        "<b>Tanggal:</b> %{x|%d %b %Y}<br>"
        "<b>Harga:</b> Rp %{y:,.2f}"
        "<extra></extra>"
    )
)
📍 Tooltip kustom
Tanggal: 15 Mar 2024
Harga: Rp 1.523,75
🔑 Pola format: %{x|%d %b %Y} untuk tanggal, %{y:,.2f} untuk angka ribuan. <extra></extra> menghapus label seri yang mengganggu.
🎞️ Animasi Temporal

Hans Rosling Style

Menganimasikan evolusi data dari tahun ke tahun dengan slider:

fig = px.scatter(
    df, x="gdpPercap", y="lifeExp",
    animation_frame="year",     # slider waktu
    animation_group="country",  # konsistensi objek
    size="pop", color="continent",
    log_x=True, size_max=60
)
1952197219922007
🎯 Kunci: animation_group menjaga identitas objek (negara) tetap konsisten antar frame, sehingga transisi mulus.
🎛️ Kontrol UI In-Chart

Dropdown Tanpa Server

Ganti metrik/format langsung di dalam grafik — tanpa backend:

fig.update_layout(
  updatemenus=[dict(
    active=0, direction="down",
    buttons=[
      dict(label="Pendapatan",
           method="update",
           args=[{"visible": [True,False,False]}]),
      dict(label="Jumlah Order",
           method="update",
           args=[{"visible": [False,True,False]}]),
    ]
  )]
)
▾ Pendapatan Bulanan
Jumlah Order Pelanggan Baru
✅ Komponen UI internal Plotly: updatemenus (dropdown/tombol), rangeslider, dan rangeselector — semuanya berjalan di browser tanpa server.

📊 Multi-Subplot

make_subplots

Beberapa panel berbagi sumbu X — dashboard dalam satu figur:

from plotly.subplots import make_subplots

fig = make_subplots(rows=2, cols=1,
    shared_xaxes=True, row_heights=[0.7, 0.3])

fig.add_trace(go.Scatter(...), row=1, col=1)
fig.add_trace(go.Bar(...),    row=2, col=1)
Panel 1 · Tren Harga Saham (70%)
Panel 2 · Volume Transaksi (30%)
🔑 shared_xaxes=True menyelaraskan sumbu X kedua panel, dan row_heights mengatur proporsi tinggi — teknik tata letak dari P5 (GridSpec) kini versi interaktif.
🌐 Web-Ready

Ekspor HTML Mandiri

Satu berkas HTML berisi grafik + pustaka JS — bisa dibuka di mana saja:

fig.write_html("dashboard.html")

# Opsi lanjutan
fig.write_html(
    "dashboard.html",
    include_plotlyjs="cdn",  # lebih ringan
    full_html=True
)
📦 Keunggulan standalone
• Pustaka Plotly JS ter-embed di dalam berkas.
• Bisa dibuka di komputer mana pun tanpa instalasi Python.
• Cukup kirim/unggah satu file → siap dibagikan.
• Interaktivitas tetap berjalan penuh (zoom, hover, animasi).
⚠️ Tips ukuran: gunakan include_plotlyjs='cdn' bila file harus ringan dan audiens punya koneksi internet.
BAGIAN IV — HANDS-ON

💻 Tiga Praktikum Plotly

Animasi temporal, dashboard multi-subplot, dan dropdown kontrol UI.

💻 Praktikum 1

Animasi Temporal 4D Gapminder

Empat dimensi + dimensi waktu = lima informasi dalam satu grafik:

df = px.data.gapminder()

fig = px.scatter(
    df, x="gdpPercap", y="lifeExp",
    animation_frame="year",
    animation_group="country",
    size="pop", color="continent",
    hover_name="country",
    log_x=True, size_max=60,
    range_x=[100, 100000], range_y=[25, 90]
)
fig.write_html("gapminder_animated.html")
🎯 Dimensi yang dipetakan
• X — PDB per kapita (log)
• Y — angka harapan hidup
• Ukuran — populasi
• Warna — benua
• Slider — tahun (waktu)
🏆 Output: berkas gapminder_animated.html — presentasi interaktif gaya Hans Rosling.
💻 Praktikum 2

Dashboard Multi-Subplot + Hovertemplate

Harga saham & volume transaksi, dengan tooltip profesional:

fig = make_subplots(rows=2, cols=1,
    shared_xaxes=True, row_heights=[0.7, 0.3])

fig.add_trace(go.Scatter(
    x=df["Tanggal"], y=df["Harga"],
    line=dict(color="#0284c7", width=2.5),
    hovertemplate="<b>Harga:</b> Rp %{y:,.2f}<extra></extra>"
), row=1, col=1)

fig.add_trace(go.Bar(
    x=df["Tanggal"], y=df["Volume"]
), row=2, col=1)
📊 Yang dibangun
Panel atas: tren harga (line) 70% tinggi. Panel bawah: volume transaksi (bar) 30%. Sumbu X tersinkronisasi sehingga zoom di satu panel ikut menggeser panel lain.
💡 Prinsip: dua metrik beda skala dalam satu dashboard — versi interaktif dari twin axes (P5).
💻 Praktikum 3

Dropdown Selektor Metrik

Mengganti metrik & judul grafik dengan updatemenus:

fig = go.Figure()
fig.add_trace(go.Bar(x=bulan, y=pendapatan,
    name="Pendapatan", visible=True))
fig.add_trace(go.Bar(x=bulan, y=order,
    name="Order", visible=False))
fig.add_trace(go.Bar(x=bulan, y=pelanggan,
    name="Pelanggan", visible=False))

fig.update_layout(updatemenus=[dict(
    buttons=[ ... 3 tombol metrik ... ])])
fig.write_html("dropdown_metric.html")
🎛️ Cara kerja
Semua trace ditambahkan sekaligus, tetapi hanya satu yang visible=True. Tombol dropdown mengubah kombinasi visible + judul + label sumbu secara instan di browser.
✅ Nilai praktis: satu berkas HTML bisa menampilkan banyak metrik tanpa memuat ulang halaman — pengalaman dashboard sesungguhnya.
🧭 Alur Kerja

Resep 5 Langkah Plotly Web-Ready

Pola yang bisa dipakai ulang untuk setiap visualisasi interaktif:

1
Siapkan Tidy Data

DataFrame rapi dari P4 (1 baris = 1 observasi) — syarat integrasi Plotly Express.

2
Mulai dengan px

px.scatter() / px.bar() untuk eksplorasi cepat.

3
Tingkatkan ke go + make_subplots

Saat butuh multi-panel, dual axis, atau kontrol UI internal.

4
Kustomisasi interaksi

hovertemplate, updatemenus, animation_frame, rangeselector.

5
Ekspor HTML mandiri

fig.write_html("nama.html") → siap dibagikan & di-deploy.
