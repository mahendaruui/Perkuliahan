⚙️ ANATOMI FUNDAMENTAL

4 Komponen Wajib Struktur Loop

Setiap perulangan di dunia komputasi dibangun oleh 4 siklus mekanis

1. Initialization

Pemberian nilai awal variabel counter sebelum loop berputar (misal: i = 1).

2. Loop Guard / Condition

Ekspresi boolean penguji apakah putaran berikutnya diizinkan (misal: i <= N).

3. Body Execution

Blok instruksi utama yang dijalankan berulang pada setiap iterasi.

4. Step / Update

Perubahan nilai counter menuju kondisi terminasi (misal: i++).

⚠️ Hukum Terminasi: Jika bagian Step / Update lupa ditulis atau tidak pernah mengubah kondisi menjadi False, program akan terjebak dalam Infinite Loop (pembekuan sistem)!

🔀 KENDALI ALIRAN ITERASI

Interupsi Loop: `break` vs `continue`

Mengontrol dinamika perputaran instruksi secara fleksibel

🔴 Perintah `break` (Terminasi Paksa)

Menghentikan seluruh perulangan seketika dan langsung melompat keluar dari blok loop, meskipun kondisi guard masih `True`. 

// Menghentikan pencarian saat data ditemukan:
for (int i = 0; i < 1000; i++) {
    if (data[i] == target) {
        cout << "Ditemukan pada indeks " << i;
        break; // Berhenti mencari!
    }
}

🟡 Perintah `continue` (Lewati Putaran)

Mengabaikan sisa instruksi di bawahnya hanya untuk putaran saat ini, dan langsung melompat ke iterasi berikutnya. 

// Hanya memproses bilangan ganjil:
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue; // Lewati genap
    cout << i << " "; // 1 3 5 7 9
}
📐 PERULANGAN BERSARANG

Perulangan Bersarang (*Nested Loop*)

Membangun dimensi ruang data 2D: Baris (Outer Loop) dan Kolom (Inner Loop)

Prinsip Dinamika Nested Loop:

Untuk setiap 1 kali putaran loop luar (*outer*), loop dalam (*inner*) akan berputar penuh sebanyak N kali.

Total Operasi = Outer_Steps × Inner_Steps = O(N²).

Pola Segitiga Bintang:

*
* *
* * *
* * * *
* * * * *
// Implementasi Segitiga Siku di C++:
int tinggi = 5;

for (int baris = 1; baris <= tinggi; baris++) {
    for (int kolom = 1; kolom <= baris; kolom++) {
        cout << "* ";
    }
    cout << "\n"; // Ganti baris
}
💻 STUDI KASUS PRAKTIKUM

Studi Kasus: Akumulator & Rata-rata Dinamis

Menerapkan pola *Sentinel Value Loop* untuk memproses input tak terbatas

🐍 Python 3 (Sentinel Loop)
# Hitung Rata-rata Input (Ketik -1 untuk berhenti)
total, count = 0, 0

while True:
    nilai = float(input("Masukkan nilai (-1 stop): "))
    if nilai == -1:
        break
    total += nilai
    count += 1

if count > 0:
    print(f"Rata-rata: {total / count:.2f}")
else:
    print("Tidak ada data masukan.")
⚡ C++ (Accumulator Pattern)
#include <iostream>
using namespace std;

int main() {
    double nilai, total = 0;
    int count = 0;

    cout << "Masukkan nilai (-1 stop):\n";
    while (cin >> nilai && nilai != -1) {
        total += nilai;
        count++;
    }

    if (count > 0)
        cout << "Rata-rata = " << total/count << "\n";
    return 0;
}
⚠️ ANOMALI & JEBAKAN LOGIKA

Jebakan Klasik Perulangan (Common Pitfalls)

Kesalahan tipikal yang memicu degradasi memori dan hang pada sistem

1. Off-by-One Error (OBOE)

Loop berputar kurang 1 kali atau lebih 1 kali akibat salah memilih operator relasional (< vs <=).

2. Modifikasi Counter Liar

Mengubah variabel counter `i` secara manual di dalam badan `for` loop, memicu loncatan iterasi tak terprediksi.

3. Floating Counter Drift

Menggunakan float sebagai counter (for(float f=0; f!=1.0; f+=0.1)) akan menjadi Infinite Loop akibat limitasi biner IEEE 754!
