📍 Tiga Geometri Vektor

Point, LineString, Polygon

Bentuk paling dasar untuk merepresentasikan fenomena di permukaan bumi:

📍 Point (0D)

Koordinat tunggal (lat, lon).
Contoh: RS, kampus, halte, menara BTS.

〰️ LineString (1D)

Urutan titik terhubung membentuk jalur.
Contoh: jalan tol, pipa, sungai.

🗺️ Polygon (2D)

Area tertutup dengan cincin batas.
Contoh: provinsi, danau, zona rawan.

💡 Prinsip pemetaan: pilih geometri sesuai fenomena — titik untuk objek tunggal, garis untuk alur, area untuk wilayah administratif.
🌐 Sistem Referensi Koordinat

WGS84 vs Web Mercator

Dua sistem koordinat yang wajib dibedakan — salah pilih, peta meleset jauh:

🌍 Geographic CRS
WGS84 · EPSG:4326

Satuan derajat desimal: latitude −90° s.d. +90°, longitude −180° s.d. +180°.

Standar baku sensor GPS dan format GeoJSON. Inilah yang dimasukkan ke Folium.

🗺️ Projected CRS
Web Mercator · EPSG:3857

Bola bumi diproyeksikan ke bidang datar 2D dengan satuan meter.

Digunakan mesin tile peta web: OpenStreetMap, Google Maps, Leaflet.

⚠️ Jebakan klasik: menukar urutan latitude/longitude. Folium menerima [lat, lon], sedangkan GeoJSON memakai urutan [lon, lat]. Salah urutan = marker muncul di negara lain.
📄 Format Pertukaran

GeoJSON

Standar terbuka berbasis JSON untuk data spasial — dibaca semua tools:

{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "id": "AC",
      "properties": { "name": "Aceh" },
      "geometry": {
        "type": "Polygon",
        "coordinates": [[[95.0,5.0], ...]]
      }
    }
  ]
}
🧩 Tiga kunci utama
• type — jenis objek (FeatureCollection).
• id — kunci penghubung ke data statistik.
• properties — atribut & metadata.
• geometry — bentuk spasialnya.
✅ Jembatan ke choropleth: kunci id inilah yang dicocokkan dengan kolom kode wilayah di DataFrame.

📍 Marker & Popup

Titik Menjadi Cerita

Marker + HTML popup + tooltip = informasi kontekstual di atas peta:

folium.Marker(
    location=[5.5501, 95.3190],
    popup=folium.Popup(popup_html, max_width=250),
    tooltip="Universitas Ubudiyah Indonesia",
    icon=folium.Icon(
        color="purple",
        icon="graduation-cap",
        prefix="fa"
    )
).add_to(peta)
🎯 Tiga lapis informasi
• Icon — warna & simbol per kategori (kampus ungu, RS merah).
• Tooltip — muncul saat hover (nama singkat).
• Popup — HTML lengkap saat diklik (tabel atribut).
💡 Kaitan P7: marker berwarna per kategori memakai saluran warna (identity) — konsisten dengan hierarki saluran Munzner.

🔥 Kepadatan Spasial

HeatMap

Mengubah ribuan titik menjadi gradasi intensitas kepadatan:

heat_data = [[lat, lon, weight]
    for lat, lon, weight
    in zip(lats, lons, bobot)]

HeatMap(
    heat_data,
    radius=14, blur=18, max_zoom=14,
    gradient={0.2: '#2563eb', 0.5: '#10b981',
              0.8: '#f59e0b', 1.0: '#ef4444'}
).add_to(peta_heat)
💡 Pemetaan warna: biru (rendah) → hijau → oranye → merah (sangat padat). Gunakan basemap gelap (dark_matter) agar kontras maksimal.
✅ Kegunaan: identifikasi zona rawan kecelakaan, sebaran permintaan layanan, atau hotspot penyakit — pola yang tak terlihat dari tabel.

🎮 Refleksi Kritis

Kuis Kilat 3 Menit

Jawab dulu, lalu klik untuk membuka jawaban:

❓ 1. Apa beda WGS84 (EPSG:4326) dan Web Mercator (EPSG:3857)?
✅ WGS84 = koordinat geografis dalam derajat desimal (standar GPS & GeoJSON). Web Mercator = proyeksi ke bidang datar bersatuan meter, dipakai mesin tile peta web (OSM/Leaflet). Folium menerima WGS84 [lat, lon].
❓ 2. Kapan perlu memakai MarkerCluster?
✅ Saat jumlah titik banyak (praktis > 50). Cluster mengelompokkan titik berdekatan menjadi satu lingkaran berisi jumlah, menjaga performa browser dan kerapian peta, lalu memecah otomatis saat di-zoom.
❓ 3. Kenapa peta choropleth bisa gagal mewarnai wilayah?
✅ Karena ketidakcocokan kunci. Nilai kolom identitas di DataFrame harus exact match dengan key_on pada GeoJSON (mis. feature.id). Beda huruf besar/kecil atau spasi tambahan → wilayah tidak terwarnai.
