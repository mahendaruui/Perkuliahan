⚖️ Dua Pendekatan

Pyplot vs Object-Oriented

Satu bergaya MATLAB, satu bergaya Python — pilih yang benar:

❌ PYPLOT (PROSEDURAL) 
plt.plot(x, y)
plt.title('Judul')
plt.xlabel('X')
• Status global tersembunyi (state-machine).
• Sulit untuk multi-panel & kustomisasi kompleks.
✅ OBJECT-ORIENTED 
fig, ax = plt.subplots()
ax.plot(x, y)
ax.set_title('Judul')
• Eksplisit, modular, presisi penuh tiap elemen.
• Standar wajib riset akademik & industri.
🎯 Aturan kelas ini: mulai P5 dan seterusnya, semua grafik memakai antarmuka OO (fig, ax). Tidak ada lagi plt.plot() terpisah.
🔬 Bedah Objek

Anatomi Grafik Matplotlib

Satu grafik adalah pohon objek — kenali setiap lapisannya:

🖼️ FigureKanvas terluar — figsize, DPI, background
📊 AxesBidang koordinat tempat data dirender
📏 AxisSumbu X/Y — label, major/minor ticks, tick labels
🔲 Spines4 garis bingkai: top, bottom, left, right
🎨 PrimitivesLines, Bars, Patches, Collections (data aktual)
📌 Legend & ColorbarPetunjuk seri data & skala warna
💬 AnnotationsPanah & teks penunjuk fokus
💡 Penting: Figure ≠ Axes. Figure adalah kanvas; Axes adalah satu bidang grafik di atasnya. Satu Figure bisa memuat banyak Axes (grid 2×2 = 4 Axes).
🛠️ Fondasi

Membuat Figure & Axes

Tiga pola dasar dari satu Axes sampai grid Axes:

# 1. Satu Axes
fig, ax = plt.subplots(
    figsize=(9, 5), dpi=300
)

# 2. Grid Axes 2x2 (array)
fig, axes = plt.subplots(
    2, 2, figsize=(12, 8)
)
axes[0,0].plot(x, y)   # panel kiri atas

# 3. Berbagi sumbu (share axis)
fig, axes = plt.subplots(
    1, 3, sharey=True
)
🧩 Parameter kunci
• figsize=(w,h) — ukuran kanvas dalam inci.
• dpi=300 — resolusi publikasi.
• sharex/sharey — skala seragam (penting untuk Small Multiples!).
⚠️ Ingat P3: untuk Small Multiples yang jujur, sharex=True & sharey=True wajib agar perbandingan antar panel valid.

🧩 GridSpec

Tata Letak Asimetris

Pecah kanvas menjadi matriks grid fleksibel dengan span baris/kolom:

import matplotlib.gridspec as gridspec

fig = plt.figure(figsize=(13, 6), dpi=250)
gs = gridspec.GridSpec(
    2, 3, figure=fig,
    width_ratios=[1.8, 1, 1]
)

# Panel kiri: span 2 baris
ax_main = fig.add_subplot(gs[:, 0])
# Panel kanan atas: baris 0, kol 1:3
ax_tr = fig.add_subplot(gs[0, 1:])
# Dua panel kanan bawah
ax_b1 = fig.add_subplot(gs[1, 1])
ax_b2 = fig.add_subplot(gs[1, 2])
Panel Utama
gs[:, 0]
Ringkasan Atas
gs[0, 1:]
gs[1, 1]
gs[1, 2]
🔑 width_ratios mengatur proporsi lebar kolom. gs[:, 0] artinya seluruh baris, kolom 0.
🔀 Twin Axes

Dua Metrik, Beda Skala

Saat satu grafik harus menampilkan unit yang berbeda (Ton vs Juta Rp/Ton):

fig, ax1 = plt.subplots(figsize=(9, 4.5), dpi=200)

# Sumbu kiri: Volume (bar)
ax1.bar(tahun, volume, color='#0284c7')
ax1.set_ylabel('Volume (Ton)', color='#0284c7')

# Sumbu kanan: Biaya (line)
ax2 = ax1.twinx()
ax2.plot(tahun, biaya, color='#e11d48', marker='s')
ax2.set_ylabel('Biaya (Juta Rp/Ton)', color='#e11d48')
📘 Baca ganda: batang biru (kiri) naik, garis merah (kanan) turun. Kesimpulan: kapasitas naik → biaya per unit turun (efisiensi).
⚠️ Hati-hati: twin axes bisa menyesatkan bila skala kedua sumbu diatur sembarangan. Pastikan narasi jelas dan label sumbu berwarna sesuai serinya.

🎨 Kustomisasi

Menuju Tufte-Style

Empat langkah menyulap grafik standar menjadi publikasi-ready:

# 1. Judul & label berstruktur
ax.set_title("Judul Insight",
    fontsize=12, fontweight='bold', loc='left', pad=15)
ax.set_xlabel("Epoch Pelatihan")
ax.set_ylabel("Akurasi (F1)")

# 2. Buang spines non-data (Tufte!)
ax.spines['top'].set_visible(False)
ax.spines['right'].set_visible(False)
ax.spines['left'].set_color('#cbd5e1')

# 3. Grid tipis bertitik
ax.grid(axis='y', linestyle=':', alpha=0.6)

# 4. Legend tanpa kotak
ax.legend(frameon=False, loc='lower right')
📐 Checklist kualitas
✅ Judul = insight, bukan sekadar variabel.
✅ Spines atas & kanan dihapus.
✅ Grid tipis (':') dan tidak mengganggu.
✅ Legend tanpa kotak (frameon=False).
✅ Kaitan P3: inilah penerapan Data-Ink Ratio Tufte langsung di kode Matplotlib.
💬 Anotasi & Legend

Memberi Makna pada Grafik

Panah & teks mengarahkan mata audiens ke titik terpenting:

ax.annotate(
    'Akurasi Maksimum (94.8%)\ntercapai pada Epoch 45',
    xy=(45, y[44]),        # titik yang ditunjuk
    xytext=(30, 0.72),       # posisi teks
    arrowprops=dict(
        arrowstyle="->",
        connectionstyle="arc3,rad=-0.2",
        color='#1e293b', lw=1.2
    ),
    fontsize=9.5, fontweight='bold',
    bbox=dict(boxstyle="round,pad=0.4",
             fc="#f8fafc", ec="#cbd5e1")
)
🎯 Anatomi annotate()
• xy — titik tujuan panah.
• xytext — posisi teks.
• arrowprops — gaya panah (lurus/melengkung).
• bbox — kotak latar teks.
💡 Prinsip narasi: anotasi mengubah grafik dari "menampilkan data" menjadi "menyampaikan temuan". Audiens tahu ke mana harus melihat.

💻 Praktikum 1

Line Plot + Confidence Band

Membandingkan konvergensi dua model AI dengan pita kepercayaan:

fig, ax = plt.subplots(figsize=(9, 5), dpi=300)

# Garis rata-rata + pita kepercayaan
ax.plot(epochs, mean_a, label='Proposed Model',
        color='#2563eb', linewidth=2.2)
ax.fill_between(epochs,
    mean_a - std_a, mean_a + std_a,
    color='#2563eb', alpha=0.18)

# Baseline (garis putus)
ax.plot(epochs, mean_b, label='Baseline SVM',
        color='#64748b', linestyle='--')

ax.savefig('akurasi.png', dpi=300,
           bbox_inches='tight')
📊 Yang dibuktikan
• fill_between() menampilkan rentang ketidakpastian (std), bukan hanya rata-rata.
• Garis putus membedakan baseline dari model utama.
🏆 Output: PNG 300 DPI siap dimasukkan ke jurnal/skripsi (bbox_inches='tight' memangkas margin kosong).
💻 Praktikum 2

Dashboard GridSpec Multi-Panel

Empat grafik berbeda dalam satu kanvas asimetris:

fig = plt.figure(figsize=(13, 6))
gs = gridspec.GridSpec(2, 3, figure=fig,
    width_ratios=[1.8, 1, 1])

ax_main = fig.add_subplot(gs[:, 0])   # line tren
ax_top  = fig.add_subplot(gs[0, 1:]) # bar produk
ax_b1   = fig.add_subplot(gs[1, 1])  # histogram
ax_b2   = fig.add_subplot(gs[1, 2])  # bar kepuasan

plt.suptitle("Dashboard Kinerja Semester I",
             fontsize=13, fontweight='bold')
🧩 Komposisi dashboard
1. Line chart tren pendapatan (panel utama kiri).
2. Bar chart produk teratas (kanan atas).
3. Histogram distribusi transaksi.
4. Bar chart indeks kepuasan.
💡 suptitle() memberi judul tingkat Figure, sedangkan set_title() untuk tiap Axes.
💻 Praktikum 3

Dual-Axis (Twinx) Chart

Menampilkan dua metrik beda skala dalam satu bidang:

fig, ax1 = plt.subplots(figsize=(9, 4.5))

# Sumbu kiri: Volume (bar)
ax1.bar(tahun, volume, color='#0284c7', alpha=0.85)
ax1.set_ylabel('Volume (Ton)', color='#0284c7')

# Sumbu kanan: Biaya (line)
ax2 = ax1.twinx()
ax2.plot(tahun, biaya, color='#e11d48',
         marker='s', linewidth=2.5)
ax2.set_ylabel('Biaya (Juta Rp/Ton)', color='#e11d48')
🔀 Kunci twinx()
ax1.twinx() membuat Axes kedua yang berbagi sumbu X tetapi punya sumbu Y sendiri di sisi kanan. Warna label disamakan dengan serinya agar tidak membingungkan.
⚠️ Narasi wajib: sebutkan hubungan kedua metrik (kapasitas naik → biaya/ton turun) agar pembaca tidak salah tafsir.

🧭 Alur Kerja

Resep 5 Langkah Grafik OO

Pola yang bisa dipakai ulang untuk grafik apa pun:

1
Buat kanvas

fig, ax = plt.subplots(figsize=..., dpi=300)

2
Gambar data

ax.plot() / ax.bar() / ax.scatter() — sebutkan label tiap seri.

3
Kustomisasi Tufte

Judul insight, label sumbu, hapus spines atas/kanan, grid tipis.

4
Anotasi & legend

Tunjuk temuan utama, legend frameon=False.

5
Ekspor

fig.savefig() — SVG untuk jurnal, PNG 300 DPI untuk slide.

🎮 Refleksi Kritis

Kuis Kilat 3 Menit

Jawab dulu, lalu klik untuk membuka jawaban:

❓ 1. Apa beda Figure dan Axes?
✅ Figure = kanvas terluar (ukuran & DPI). Axes = bidang koordinat tempat data dirender. Satu Figure dapat memuat banyak Axes (mis. grid 2×2 = 4 Axes).
❓ 2. Kenapa sharex=True, sharey=True penting untuk Small Multiples?
✅ Agar semua panel memakai skala identik. Kalau tiap panel beda skala, perbandingan antar panel menjadi menipu (melanggar prinsip integritas P3).
❓ 3. Kapan memakai ax1.twinx()?
✅ Saat menampilkan dua metrik dengan skala/unit berbeda pada satu bidang (mis. volume Ton + biaya Juta Rp/Ton), sehingga masing-masing punya sumbu Y sendiri di kiri dan kanan.
