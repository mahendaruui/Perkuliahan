⚠️ Missing Values

MCAR, MAR, & MNAR

Tidak semua data hilang itu sama — diagnosis menentukan strategi imputasi:

MCAR
Hilang murni acak, tak terkait variabel lain. Sensor putus, transmisi gagal.
Aman: drop jika < 5%, atau imputasi mean/median.
MAR
Pola hilang terkait variabel lain yang teramati. Contoh: responden wanita jarang mengisi berat badan.
Solusi: imputasi per grup (groupby median).
MNAR
Hilang terkait nilai itu sendiri. Nasabah utang macet sengaja tidak isi pendapatan.
Solusi: pemodelan khusus + flag is_missing.
⚠️ Jangan asal drop! Menghapus baris MNAR bisa membuat data bias sistematis — kesimpulan jadi salah arah.
🩹 Strategi Imputasi

Pilih Obat yang Tepat

Empat teknik dari yang paling sederhana ke paling kontekstual:

TeknikKapan DipakaiKode Pandas
DropHilang < 5% & MCARdf.dropna()
KonstantaKategori hilangfillna('Other')
StatistikNumerik, sebaran normal/robustfillna(median)
Per GrupMAR — pola bergantung kelompokgroupby().transform()
 
# Imputasi Revenue berdasarkan median per Kategori
df['Revenue_IDR'] = df.groupby('Category')['Revenue_IDR'].transform(
    lambda x: x.fillna(x.median())
)
# Fallback: median global untuk sisa NaN
df['Revenue_IDR'] = df['Revenue_IDR'].fillna(df['Revenue_IDR'].median())

📐 Tukey's Fences

Metode IQR

Non-parametrik & tangguh untuk data yang tidak berdistribusi normal:

IQR = Q3 − Q1  •  Bawah = Q1 − 1.5×IQR  •  Atas = Q3 + 1.5×IQROutlier jika x < Batas Bawah atau x > Batas Atas
◀ Outlier Kiri
Q1 Median Q3
Outlier Kanan ▶
📦 Kotak = 50% data tengah (Q1–Q3). Whisker = 1.5×IQR. Titik di luar whisker = pencilan.
⚖️ Dua Senjata

Z-Score vs IQR

Pilih berdasarkan bentuk sebaran data — bukan berdasarkan selera:

AspekZ-ScoreIQR (Tukey)
AsumsiNormal / mendekati normalBebas asumsi (non-parametrik)
Ambang|z| > 3 (atau 2.5)x > Q3 + 1.5×IQR
Rumusz = (x − μ) / σIQR = Q3 − Q1
Kelemahanμ & σ sendiri terdistorsi outlierKurang sensitif pada ekor panjang
Cocok untukData sensor, pengukuran fisikaData finansial, transaksi, skewed
⚠️ Fakta pahit: karena mean dan standar deviasi ikut terpengaruh outlier, Z-Score bisa "menyembunyikan" pencilan ekstrem. Untuk data transaksi kotor, IQR lebih aman.
🛠️ Perlakuan Outlier

Jangan Langsung Hapus!

Tiga pilihan — dan konsekuensi visualnya:

🗑️
Drop / Filter
Buang baris pencilan. Skala rapi, tapi berisiko membuang kejadian langka yang justru penting (fraud!).
✂️
Capping (Winsorizing)
Ganti nilai > batas atas dengan batasnya. Skala tetap terjaga, kejadian ekstrem ditandai.
🏷️
Pertahankan + Flag
Simpan nilai asli, tambah kolom is_outlier. Analisis & visualisasi jadi transparan.
# Capping ke batas atas (Winsorizing)
df['Revenue_Capped'] = np.where(
    df['Revenue_IDR'] > ub, ub, df['Revenue_IDR']
)
BAGIAN IV — AGREGASI & RESHAPING

🔄 Merangkum & Membentuk Ulang

Tiga senjata utama: groupby, pivot_table, dan melt.

14 / 20
🧮 groupby

Multi-Agregasi Sekaligus

Pecah-apply-gabung: satu perintah, banyak ringkasan:

summary = df.groupby('Category').agg(
    Total_Revenue=('Revenue_Capped', 'sum'),
    Rata_Rata=('Revenue_Capped', 'mean'),
    Total_Qty=('Quantity', 'sum'),
    Jumlah_Trx=('Transaction_ID', 'count')
).reset_index()
💡 Pola pikir Split-Apply-Combine
1. Split data per kategori.
2. Apply fungsi agregasi tiap grup.
3. Combine hasil jadi tabel ringkas.
✅ reset_index() mengubah index grup menjadi kolom biasa — siap untuk plot.
📊 pivot_table

Tabulasi Silang

Dua dimensi kategori jadi matriks — format Wide untuk laporan:

pivot = pd.pivot_table(
    df,
    values='Revenue_Capped',
    index='Customer_City',
    columns='Category',
    aggfunc='sum',
    fill_value=0
)
🧩 Anatomi
index = baris, columns = kolom, values = angka, aggfunc = cara merangkum, fill_value = isi sel kosong.
⚠️ Ingat: pivot menghasilkan format Wide. Bagus untuk laporan, tapi perlu di-melt sebelum diplot.
🔄 pd.melt()

Unpivot: Kembali ke Tidy

Mengubah kolom menjadi baris agar siap dipetakan ke sumbu grafik:

tidy = pivot.reset_index().melt(
    id_vars='Customer_City',
    var_name='Category',
    value_name='Total_Revenue_IDR'
)
🧩 Tiga parameter
• id_vars — kolom yang tetap (identitas).
• var_name — nama kolom baru hasil "peleburan" nama kolom.
• value_name — nama kolom baru hasil nilai.
✅ Alur lengkap: kotor → bersih → pivot (laporan) → melt (tidy) → plot Seaborn/Plotly.

🎮 Refleksi Kritis

Kuis Kilat 3 Menit

Jawab dulu, lalu klik untuk membuka jawaban:

❓ 1. Kapan memakai pd.melt() dan kapan pivot_table()?
✅ melt = Wide → Long (siap plot, untuk hue). pivot_table = Long → Wide (tabulasi silang untuk laporan). Keduanya saling berkebalikan.
❓ 2. Kenapa IQR lebih aman daripada Z-Score untuk data transaksi kotor?
✅ Karena IQR berbasis kuartil (non-parametrik) dan tidak terdistorsi outlier. Z-Score memakai mean & standar deviasi yang justru ikut terpengaruh oleh pencilan itu sendiri.
❓ 3. " Banda Aceh " dan "banda aceh" — apa akibatnya jika tidak dibersihkan?
✅ Dianggap dua kota berbeda saat groupby → total terpecah, urutan ranking salah, peta salah. Perbaikan: .str.strip().str.title().
