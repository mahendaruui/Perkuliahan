🏛️ Kerangka Cetak Biru

Abstract Class & Abstract Method

Class induk yang mewajibkan seluruh subclass untuk mengimplementasikan method tertentu:

// Abstract Class: Tidak bisa diinstansiasi ($obj = new BangunDatar() -> ERROR)
abstract class BangunDatar {
    public function __construct(protected string $nama) {}

    // Concrete Method: Sudah memiliki isi fungsional
    public function getNama(): string { return $this->nama; }

    // Abstract Methods: WAJIB diisi rumus oleh subclass
    abstract public function hitungLuas(): float;
    abstract public function hitungKeliling(): float;
}

class Persegi extends BangunDatar {
    public function __construct(private float $sisi) { parent::__construct("Persegi"); }
    public function hitungLuas(): float { return $this->sisi ** 2; }
    public function hitungKeliling(): float { return 4 * $this->sisi; }
}
📜 Standarisasi Kontrak

Interface (Kontrak Murni)

Mendefinisikan daftar method yang WAJIB dimiliki class tanpa membawa data properti:

// Deklarasi Interface
interface NotifikasiInterface {
    public function kirim(string $ke, string $pesan): bool;
}

// Implementasi oleh Class
class EmailNotifikasi implements NotifikasiInterface {
    public function kirim(string $ke, string $pesan): bool {
        echo "📧 Kirim Email ke {$ke}: '{$pesan}'\n";
        return true;
    }
}
Ciri Khas Interface di PHP:
1. Menggunakan kata kunci interface dan dihubungkan dengan implements.
2. Semua method di dalamnya otomatis bersifat public abstract.
3. Tidak boleh memiliki properti biasa (hanya boleh konstanta const).
4. Tidak memiliki constructor.
🔗 Kontrak Ganda

Multiple Interface Implementation

Satu class di PHP dapat mengimplementasikan banyak interface sekaligus:

interface KirimPesan { public function kirim(string $teks): void; }
interface LogAudit   { public function catatWaktu(): void; }
interface Enkripsi   { public function enkripsiData(): string; }

// Menggabungkan 3 kontrak kemampuan sekaligus:
class WhatsAppService implements KirimPesan, LogAudit, Enkripsi {
    public function kirim(string $teks): void { echo "📲 Pesan WA: {$teks}\n"; }
    public function catatWaktu(): void { echo "⏱️ Log dicatat.\n"; }
    public function enkripsiData(): string { return "🔐 SHA-256 Encrypted"; }
}
⚖️ Panduan Keputusan Desain

Abstract Class vs Interface

Matriks komparasi untuk menentukan arsitektur yang tepat:

Kriteria Abstract Class Interface
Kata Kunci abstract class & extends interface & implements
Jumlah Implementasi ❌ Single Inheritance (Hanya 1 parent) ✅ Multiple (Bisa banyak interface)
Properti / State ✅ Bebas (public, protected, private) ❌ Hanya konstanta (const)
Isi Method Campuran (Bisa konkret + abstract) Murni deklarasi tanpa isi tubuh
Constructor ✅ Bisa memiliki __construct() ❌ Tidak boleh ada constructor
Filosofi Relasi IS-A (Keluarga biologis objek) CAN-DO (Sertifikasi keahlian/perilaku)
📦 Fitur Modern PHP 8.1

Backed Enum untuk Tipe Data Aman

Menghindari kesalahan pengetikan string (*magic strings*) pada status aplikasi:

enum StatusPesanan: string {
    case PENDING = 'Menunggu Pembayaran';
    case PROSES  = 'Sedang Dikemas';
    case KIRIM   = 'Dalam Pengiriman';
    case SELESAI = 'Pesanan Diterima';

    public function getIcon(): string {
        return match($this) {
            self::PENDING => "⏳",
            self::PROSES  => "📦",
            self::KIRIM   => "🚚",
            self::SELESAI => "✅",
        };
    }
}

$status = StatusPesanan::KIRIM;
echo $status->getIcon() . " " . $status->value; // 🚚 Dalam Pengiriman
🔔 Praktikum Terbimbing

Studi Kasus: Sistem Notifikasi Kampus

Menerapkan interface notifikasi terstandar untuk Email, SMS, dan WhatsApp:

interface ChannelNotifikasi {
    public function kirimNotifikasi(string $target, string $judul): void;
}

class PusatPemberitahuan {
    public function broadcast(ChannelNotifikasi $ch, string $target, string $msg): void {
        $ch->kirimNotifikasi($target, $msg);
    }
}
Mengapa Pendekatan Ini Sangat Tangguh?
• Jika kampus ingin menambah channel notifikasi baru (misal: Telegram Bot atau Push Notification), cukup buat class baru implements ChannelNotifikasi.

• Class PusatPemberitahuan tetap utuh tanpa perlu diedit ulang!
