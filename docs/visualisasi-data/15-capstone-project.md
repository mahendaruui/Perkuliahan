# 🚀 Modul 15: Integrasi Proyek Capstone Visualisasi Data

## 🎯 Capaian Pembelajaran (Sub-CPMK 3 & 4)
Setelah mempelajari modul ini, mahasiswa diharapkan mampu:
1. Mengintegrasikan seluruh kompetensi dari modul 1 s.d. 14 ke dalam satu proyek akhir komprehensif.
2. Memilih studi kasus nyata (Kesehatan, Finansial, E-Commerce, Smart City, Lingkungan/Bencana).
3. Membangun aplikasi web dashboard interaktif mandiri (*Streamlit*) yang terhubung dengan dataset riil.
4. Menyusun laporan teknis akademik dan repositori GitHub yang rapi berstandar *Clean Code*.

---

## 📋 Ketentuan Proyek Capstone Terpadu

### 1. Pilihan Domain Studi Kasus:
- **Domain A:** Analitik Kesehatan Publik & Epidemiologi Wilayah (GIS Map + Trend + Forecasting).
- **Domain B:** Dashboard Finansial, Investasi & Analisis Risiko Pasar.
- **Domain C:** Sistem Intelijen Bisnis E-Commerce & Segmentasi Pelanggan (RFM Analysis).
- **Domain D:** Pemantauan Kualitas Lingkungan, Sensor IoT & Kebencanaan Alam (Aceh / Indonesia).

### 2. Spesifikasi Teknis Wajib:
1. **Data Pipeline:** Menggunakan dataset riil minimal **1.000+ baris data** dengan proses data cleaning & wrangling terdokumentasi.
2. **Dashboard Streamlit:**
   - Memiliki minimal **3 Halaman / Tab Analisis**.
   - Dilengkapi widget filter interaktif dinamis (*Date range, Multi-select, Metric cards*).
   - Memuat minimal 1 peta geospasial (*Folium / Plotly Map*).
   - Memuat visualisasi statistik multivariat (*Plotly / Seaborn*).
3. **Dokumentasi & Repositori:**
   - Repositori GitHub publik lengkap dengan `README.md`, class diagram/arsitektur, dan petunjuk instalasi (`requirements.txt`).
