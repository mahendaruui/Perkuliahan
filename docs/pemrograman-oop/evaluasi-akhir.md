# Minggu 16: Evaluasi Akhir Semester & Presentasi Proyek

## 🎯 Capaian Pembelajaran (Sub-CPMK 6)
Setelah menyelesaikan evaluasi ini, mahasiswa mampu:
1. Mempresentasikan hasil pengembangan aplikasi berbasis objek secara komprehensif.
2. Mempertanggungjawabkan keputusan desain class, pilar OOP, dan algoritma yang diimplementasikan.
3. Mendemonstrasikan fungsionalitas sistem secara langsung (*live demo*).
4. Menyusun dokumentasi teknis dan laporan akhir proyek.

---

## 🎤 Format dan Teknis Presentasi

Setiap kelompok/peserta akan mempresentasikan hasil proyek dengan ketentuan sebagai berikut:
- **Durasi Presentasi:** 10 menit presentasi dan demo aplikasi + 5 menit sesi tanya jawab dosen dan audiens.
- **Media Presentasi:** Slide presentasi (PowerPoint / Canva / Google Slides) & Source code aktif di IDE.
- **Kesiapan Teknis:** Aplikasi sudah siap dijalankan sebelum giliran presentasi dimulai (*no build error*).

---

## 📑 Struktur Slide Presentasi

Slide presentasi dianjurkan memuat poin-poin berikut (maksimal 7–10 slide):
1. **Slide Judul:** Nama Sistem, Nama Anggota Kelompok & NIM.
2. **Latar Belakang & Masalah:** Masalah apa yang diselesaikan oleh aplikasi ini?
3. **UML Class Diagram:** Struktur class, hierarki inheritance, interface, dan relasi antar entitas.
4. **Penerapan Pilar OOP:**
   - Di mana letak *Encapsulation* diterapkan?
   - Di mana letak *Inheritance* dan *Polymorphism* digunakan?
   - Di mana letak *Abstraction (Interface/Abstract Class)* digunakan?
5. **Fitur Unggulan:** Exception handling, collection yang dipakai, dan mekanisme File I/O.
6. **Live Demo Aplikasi:** Menjalankan skenario penggunaan utama dan skenario *error handling*.
7. **Kesimpulan & Saran:** Pembelajaran yang didapat dan rencana pengembangan di masa depan.

---

## 📊 Rubrik Penilaian Proyek Akhir (UAS - Bobot 25%)

| Kriteria | Bobot | Deskripsi Penilaian |
| :--- | :---: | :--- |
| **Penerapan Konsep & Pilar OOP** | 30% | Kebenaran implementasi Encapsulation, Inheritance, Polymorphism, dan Abstraction sesuai kebutuhan sistem. |
| **Kualitas Kode & Clean Code** | 20% | Penataan package rapi, penamaan variabel/class sesuai konvensi Java, minim duplikasi kode. |
| **Robustness & Error Handling** | 15% | Penggunaan blok try-catch, custom exception, aplikasi tidak crash saat input tidak valid. |
| **Fitur & Persistensi Data (File I/O)** | 15% | Fungsionalitas aplikasi berjalan lancar, data tersimpan dan dapat dimuat kembali dari berkas disk. |
| **Presentasi & Penguasaan Materi** | 20% | Kemampuan menjelaskan logika program, menjawab pertanyaan teknis saat tanya jawab, dan kerja sama tim. |
